## 2쪽. 기획을 작동하는 결과물로 확인합니다

### 본문

저는 전투·시스템을 설계하고, 구현 결과를 확인하며 수정하는 게임 기획자입니다. 실무에서는 스킬과 전투 규칙을 직접 구현하고, 공통 제작 구조와 데이터 자동화를 다뤘습니다. 결사에서는 AI를 활용해 규칙을 플레이 가능한 게임으로 만들고, 직접 플레이와 자동 측정으로 수정 방향을 결정했습니다.

| 기획자로서 하는 일 | 결사에서 보여 주는 사례 |
|---|---|
| 플레이어가 무엇을 선택할지 설계 | 이동과 판정에 같은 주사위를 사용 |
| 기획을 작업 가능한 조건으로 전달 | 행동 비용·예외·차례 종료·시험을 지시서로 정리 |
| 구현 결과를 판단하고 수정 | 거점 미션의 투옥 문제를 발견하고 구조 변경 |

**본인 담당:** 기획 방향, 규칙 선택·개정, 작업 범위와 우선순위, 구현 지시, 플레이 검수, 수정 결정.

**AI 활용:** 조사·대안 정리·문서화 보조, 코드 구현, 시험·자동 플레이·측정·보고, 이미지 생성.

**작업 흐름:** 문제 확인 → 대안 비교와 결정 → 구현 지시 → 결과 검토 → 플레이 검수 → 개선.

### 본문

**준비를 더 하면 돌파할 자원이 늘지만, 남은 시간은 줄어듭니다.**

1막에는 지도에서 미션을 수행해 첩보와 결행 준비를 확보합니다. 팀은 더 준비할지, 거점을 정해 결행할지 선택합니다. 2막에는 선택한 거점의 장면을 순서대로 돌파합니다. 남은 날과 경찰 추격, 일제 동향이 이 결정에 압박을 줍니다.

**준비 → 첩보·결행 준비 확보 → 결행 결정 → 장면 돌파 → 성패와 개인 사연 후일담**

|---|---|---|
| 큰 눈을 이동에 사용 | 더 먼 목적지에 도달 | 판정에 남길 큰 눈 감소 |
| 주사위를 동료에게 건넴 | 동료의 행동·판정 지원 | 자신의 행동 기회 소비 |

## 5쪽. 사례 A — 큰 주사위를 이동에 쓸까, 판정에 남길까?

### 본문

**이동 거리와 판정 성공 가능성이 같은 자원을 소비하도록 설계했습니다.**

초기 팀 주사위 분배는 1인과 AI 동료가 함께하는 환경에서 협의할 여지가 적었습니다. 이동과 판정에 어떤 눈을 배분할지 고르게 하려고 개인 작전 주사위를 선택했습니다.

| 검토한 방식 | 기대한 효과 | 고려한 비용 |
|---|---|---|
| 고정 행동 점수 | 일정한 행동량 | 이동의 운 요소 감소·관련 수치 재조정 |
| 개인 작전 주사위 · 채택 | 눈을 보고 이동과 판정 배분 | 낮은 눈의 활용처·판정 난이도 조정 |

이동에는 주사위 눈만큼의 거리를, 판정에는 **낸 눈 + 새 주사위 1개**를 사용합니다. 후속 행동 제한으로 같은 주사위를 두 행동에 다시 쓸 수 없게 했습니다.

**규칙 설명용 예시: 내 주사위 6과 3 / 판정 목표 9 / 보정 없음**

- 3칸 앞 미션을 수행하려면: 3으로 이동하고 6으로 판정. 새 눈 3 이상이면 성공하므로 확률은 **66.7%**입니다.
- 6칸 앞의 다른 목적지로 가려면: 6을 이동에 사용. 더 멀리 갈 수 있지만 6을 판정에 남길 기회는 포기합니다.

눈 3으로 목표 9 판정을 하면 성공 확률은 **16.7%**입니다. 큰 눈은 이동과 판정 모두에 가치가 있으므로, 현재 위치와 오늘의 목적에 따라 배분이 달라집니다.

**구현 결과:** 이동과 판정을 같은 자원으로 연결하고, 예비 주사위 메뉴를 제거했습니다.

### 편집 메모와 근거

- 화면: [주사위 영역](img/dice_bar.jpg). 오른쪽에는 두 목적지의 가상 상황 도식을 새로 그린다.
- 도식에 `규칙 설명용 예시`를 붙인다. 실제 판에서 관찰한 상황으로 표현하지 않는다.
- 성공 확률은 공정한 6면체 주사위 1개의 가능한 결과로 계산했다.
- 근거: [개인 주사위](../v2_구현/7단계_개인주사위.md), [행동 제한](../v2_구현/11단계_행동_제한.md).

## 6쪽. 사례 B — 설계 의도를 구현 조건으로 전달하다

### 본문

**AI에 행동 구조를 맡길 때, 비용·예외·종료 조건과 검증 범위를 함께 전달했습니다.**

개인 주사위 도입 이후에도 한 차례에 여러 일을 수행할 수 있었습니다. 행동을 고르면서 다른 행동을 포기하게 하려고 `주사위 하나 = 행동 하나`를 선택했습니다.

| 구현 조건 | 전달한 기준 |
|---|---|
| 일반 행동 | 이동·판정·바치기·건네기 등에 주사위 하나 소비 |
| 예외와 한도 | 아이템 차례당 1장, 능력의 사용 한도와 주사위 비용 예외 구분 |
| 차례 종료 | 이동 종료와 차례 종료를 분리, 남은 주사위가 있어도 종료 가능 |
| 연결 기능 | 저장·재개·AI 동료·화면도 같은 행동 규칙 반영 |
| 완료 기준 | 새 규칙별 시험과 300판 전후 측정, 밸런스 조정은 별도 단계 |

**실제 구현 지시서 발췌**

> 낮을 **「주사위 1개 = 행동 1개」**로 바꾼다.
>
> 차례가 끝나는 조건을 「이동을 마치면」에서 **`end_turn`(차례 마치기)**으로 바꾼다.
>
> 행동마다 주사위 하나를 고르고, 쓴 주사위는 `used`가 된다.

**본인의 판단:** 행동 비용과 예외, 작업 범위, 완료 기준 결정.

**AI 수행:** 규칙 엔진·화면·AI 동료 수정, 시험·측정과 결과 보고.

### 편집 메모와 근거

- 실제 지시서 일부를 읽기 좋은 크기로 배치한다. 긴 코드나 대화 캡처는 생략한다.
- 근거: [B 차례 구조 지시서](../v2_구현/지시서/B_차례구조.md).
- 상세 예외는 부록으로 보낸다. 본문에서 모든 능력이 무료라고 단순화하지 않는다.

## 8쪽. 사례 C — 미션 수행 중 반복되는 투옥을 발견하다

### 본문

**미션이 요구한 거점 진입과 경찰 등장 규칙이 충돌했습니다.**

직접 플레이에서 거점에 들어가는 미션을 확인하던 중, 경찰에 잡혀 미션을 이어가기 어려운 상황을 발견했습니다. 규칙 시험을 통과했더라도, 여러 규칙이 결합한 플레이 상황은 따로 확인해야 했습니다.

**문제의 구조**

거점 진입 → 경찰이 붙음 → 가장 가까운 거점에서 등장 → 요원이 선 칸이 등장 위치가 될 수 있음.

**첫 수정**

거점 안이나 바로 옆에서 붙는 경찰이 **3칸 떨어진 곳**에 나타나도록 바꿨습니다. 같은 칸에서 경찰이 등장하는 직접 충돌을 피하도록 한 수정입니다.

다만 이 변경 후에도 미션은 거점 진입을 요구했습니다. 후속 검수에서는 경찰 등장 거리뿐 아니라 미션의 수행 장소를 다시 검토했습니다.

### 편집 메모와 근거

- 변경 전후 등장 위치를 문서 기반 도식으로 그린다. `문서 기반 재구성`이라고 표시한다.
- 미확인 투옥률 39%→34%와 신뢰수준이 없는 오차값은 넣지 않는다.

## 9쪽. 사례 C — 등장 거리에서 미션 구조까지 바꾸다

### 본문

**1막은 거점 주변에서 준비하고, 2막은 거점 안을 돌파하도록 역할을 나눴습니다.**

경찰 등장 거리를 조정한 뒤, 거점 진입을 요구하던 미션 5장을 옆 칸에서 수행하도록 변경했습니다. 새로운 규칙을 늘리는 대신 기존의 바치기·잠복·운반·협동 조건을 재사용했습니다.

| 미션 | 변경 전 | 변경 후 |
|---|---|---|
| 형무소 간수 매수 | 형무소 진입 | 옆 칸에서 주사위 합 6 바치기 |
| 총독부 설계도 입수 | 총독부 진입 | 옆 칸에서 쫓기지 않고 차례 종료 |
| 경찰서 문서 탈취 | 내부에서 문서 반출 | 옆 칸에서 받아 출발점까지 운반 |
| 군영 보급 장부 | 내부에서 장부 수령 | 옆 칸에서 받아 시내로 운반 |
| 경찰서 앞 양동 | 한 요원 진입·다른 요원 인접 | 두 요원이 같은 날 옆 칸에서 차례 종료 |

카드 ID·보상·결행 준비 값은 유지해 저장, 개인 사연, 요원 특성과의 연결을 보존했습니다.

**확인:** 미션 변경 전후 AI 4명 1,000판 승률은 55.2%와 54.4%로 기록됐습니다. 변경 후 AI 시험 220판에서 멈춤·반칙은 0으로 보고됐습니다.

**판단:** 등장 거리 조정은 직접 충돌을 줄이고, 수행 장소 변경은 준비와 돌파의 역할을 나눴습니다. 플레이에서 발견한 문제를 미션이 요구하는 행동까지 연결해 수정했습니다.

### 편집 메모와 근거

- 대표 카드 하나는 그림으로 전후 비교하고 나머지는 짧은 표로 배치한다.
- 최신 `형무소 간수 매수` 카드와 옆 칸 마커의 실제 캡처를 추가 확보한다. 이전 상태는 재구성 도식으로 표시한다.
- 승률 변화는 이 버전의 전체 결과다. 투옥 문제의 완전 해결이나 사람 체감 개선으로 해석하지 않는다.
- 근거: [P1 변경·측정](../v2_구현/지시서/P_출시후_다듬기.md), 커밋 `dca02a0`.

## 10쪽. 전체 승률과 거점별 차이를 함께 확인하다

### 본문

**평균 승률이 목표 안에 있어도, 거점에 따라 결과가 다르면 추가 조정이 필요했습니다.**

측정 목표는 AI 4명 기준 승률 45~55%, 거점별 최대 격차 15%p 이내였습니다. 미션 변경 이후 전체 승률은 54.4%였지만, 거점별 격차는 18.2%p로 목표를 벗어났습니다.

마지막 장면의 목표를 1 바꿔도 결과가 크게 움직여, 다른 장면의 목표를 함께 조정하는 후보 9개를 비교했습니다. AI가 후보 측정과 보고를 수행했고, 기획 기준에 맞춰 결과를 검토했습니다.

**AI 4명·버전별 1,000판·동일 시작 시드 610000**

| 거점 | 조정 전 | 조정 후 | 조정 후 선택된 판 수 |
|---|---|---|---|
| 군영 | 44.5% | 54.3% | 339 |
| 총독부 | 62.7% | 56.1% | 244 |
| 경찰서 | 60.0% | 50.2% | 285 |
| 형무소 | 52.3% | 52.3% | 132 |
| 전체 | 54.4% | 53.3% | 1,000 |
| 거점 최대 격차 | 18.2%p | 6.0%p | — |

다른 시작 시드 910000의 1,000판에서는 승률 **53.2%**, 거점 격차 **14.8%p**였습니다. 전체 승률은 두 묶음에서 비슷했지만 거점 격차에는 변동이 남았습니다.

**이후 점검:** 직접 플레이에서 AI 동료가 낸 눈 1로 목표 10 판정(성공 0%)을 하는 장면을 보았고, 측정하니 판당 13.8번이었습니다. 0%면 판정하지 않고 주사위를 동료에게 건네게 하자 4.2번으로 줄었고, AI가 강해져 승률이 57.1%로 올랐습니다. 가장 높던 총독부·군영의 장면 판정 하나씩을 10 → 11로 맞춰 **51.3%**(다른 시드 55.1%), 격차 6.7%p(12.5%p)가 되었습니다.

**규칙 단순화:** 측정에서 거의 쓰이지 않던 군자금(82%의 판이 0으로 끝남) · 미끼(0번) · 아이템 건네기 · 구출을 뺐습니다. 뺀 직후 59.4%로 오른 승률을 형무소 · 총독부 장면 판정 한 칸씩으로 맞춰 **53.7%**(다른 시드 50.6%), 격차 13.0%p(7.3%p)입니다.

### 편집 메모와 근거

- 거점별 전후 막대그래프와 다른 시드 결과를 함께 배치한다.
- 거점별 수치는 AI가 그 거점을 선택한 판의 결과다. 표본 수가 다르고 거점을 강제한 동등 조건 실험이 아니다.
- 격차는 원자료의 최대·최소 승률로 계산한 뒤 소수 첫째 자리로 반올림했다. 과거 초안의 다른 시드 14.9%p는 14.8%p로 바로잡았다.
- 근거: [P6 조정 기록](../v2_구현/지시서/P_출시후_다듬기.md), [점검 반영](../v2_구현/점검_반영.md). 원자료 파일(`data/balance_1000*.json`)은 점검 반영 뒤 측정으로 바뀌었다. 표의 P6 수치는 그 당시 기록(P 지시서)에서 가져온다.
