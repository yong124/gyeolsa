# 규칙 정돈안 (v1.3 기준, 2026-10-01)

> **결정과 적용 (2026-10-01):** A1~A4 전부 적용, 미션 교체는 자동(건네기·미끼는 플레이 테스트 뒤 결정), 노출은 강화.
> 노출은 처음 안(문턱마다 출동 + 노출 끝에 강제 결행)으로 해 보니 2인이 일찍 결행하게 되어 오히려 쉬워졌습니다(2인 74%).
> 최종안: **매일 +1 삭제**(시끄러운 행동으로만 오름), **경계 오를 때 출동**, **결행 때의 경계가 2막 내내 이어지고 결행 판정을 어렵게 함**.
> 적용 뒤 작전 일수를 2인 17일, 4인 10일로 다시 맞췄습니다. 결과는 `결사_기획서.md` 16.12.

지금 규칙을 모두 적고, 규칙마다 **얼마나 쓰이는지**와 **빼면 결과가 얼마나 바뀌는지**를 재서 정리할 후보를 골랐습니다.
측정은 AI끼리 인원별 300판씩(`tests/rule_audit.gd`)입니다. **AI가 잘 못 쓰는 규칙은 과소평가될 수 있으므로**, 결정 전에 사람 플레이테스트(`플레이테스트_가이드.md`)로 확인할 항목을 따로 표시했습니다.

## 3. 정돈 제안

### A. 확실한 것 (데이터가 분명함)

**A1. "광복수치 목표치 도달 → 즉시 결행" 삭제.** 900판 중 한 번도 일어나지 않았습니다. 그런데 상단 바에 "3 / 10"으로 크게 표시돼 목표가 10인 것처럼 보이게 합니다.
→ 2막 구조에서는 광복수치를 **결행 준비도**로 바꾸고, 바에는 투표가 열리는 칸(5)만 표시합니다.

**A2. 이벤트 카드 13종 → 6종 안팎.** 이벤트는 판당 4장씩 뽑히지만 결과에 영향이 없습니다(±1%p). 13종 가운데 4종은 "다음 차례 이동 ±N"뿐입니다.
- 이동 증감 4종(꽈당·불량배·지름길·인력거)은 1~2종으로 줄입니다.
- 경찰 소환 2종(경찰출동·밀고자)과 경찰 제거 2종(절호의 기회·만세)은 각각 하나로 합칩니다.
- 남길 것: 탈옥(집단 탈옥)처럼 판을 바꾸는 카드.
- 이벤트 타일 30장은 15~20장으로 줄여 "뽑는 빈도"도 낮춥니다.

**A3. 아이템 12종 → 7~8종.** 판당 3장 뽑히지만 빼도 결과가 같습니다(-1.7%p).
- 망원경과 소음기는 둘 다 "암살 +1"이므로 하나로 합칩니다.
- 조건이 복잡한 뇌물("경계 1단계일 때, 다른 아이템을 버리고…")과 위장 신분증("경계 1~2단계일 때…")은 단순하게 고치거나 뺍니다.
- 저격총은 효과가 겹치는 망원경과 정리합니다.
- 남길 것: 옷핀, 연막탄, 승차권처럼 **쓰는 순간이 분명한** 카드.

**A4. 전차 역 삭제 (또는 기본 끔).** 한 판에 0.03번 탑니다. 빼면 오히려 승률이 오릅니다(+3.6%p). 보드의 11종 칸 중 하나를 줄일 수 있습니다.

### B. 사람 테스트로 확인한 뒤 정할 것 (AI가 잘 못 쓸 가능성)

**B1. 협력 3종 (건네기, 미끼, 미션 교체).** AI는 거의 쓰지 않고 결과에도 영향이 없지만, 사람 사이의 협력 대화를 만드는 장치일 수 있습니다. 행동 바의 버튼 4개 중 3개를 차지합니다.
→ 제안:
- **미션 교체**는 불가능한 미션만 자동으로 바꿉니다 (버튼 제거).
- **건네기**는 같은 칸이나 옆 칸에서 자유롭게 주고받게 합니다 (차례당 아이템 사용으로 치지 않음).
- **미끼**는 플레이테스트 결과를 보고 결정합니다.

**B2. 노출 트랙.** 꺼도 +2%p 차이뿐입니다. 즉 "오래 정찰하면 위험해진다"는 압박이 약합니다. 노출은 결행 시점 고민의 핵심이라 없애기보다 **강화**를 제안합니다. 예:
- 경계 3단계가 되면 다음 날 아침 강제 결행.
- 노출 문턱을 넘을 때마다 즉시 거점 출동.

**B3. 감옥.** 판당 4~4.5번 투옥되고, 가장 많이 굴리는 판정이 탈옥입니다. 사람에게는 "갇혀서 주사위만 굴리는 차례"가 지루할 수 있습니다. 설문의 "답답했던 순간"에서 확인합니다.

### C. 유지 (핵심)

세력 능력, 결행 투표, 일제 동향은 판을 크게 움직이므로 유지합니다. 일제 동향은 끄면 승률이 13%p 오를 만큼 어려움의 주된 원천입니다. 난이도 조절 손잡이로 쓸 수 있습니다.

## 4. 실험 방법

`GameRules.scenario["off"]`로 규칙을 끈 판을 만들 수 있고, `tests/rule_audit.gd`가 기준과 비교합니다. 규칙을 고친 뒤 같은 측정을 다시 돌려 핵심 수치(인원별 대성공 45~55%, 결행 시점, 판 길이)가 유지되는지 확인합니다.
