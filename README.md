## 어떤 게임인가
- **남은 날은 아흐레.** 1막에는 덮인 경성 지도를 넓혀 가며 미션을 이루고 첩보를 모읍니다. 결행 준비가 차면 투표로 결행을 선언합니다. 2막에서는 고른 거점(형무소 · 군영 · 경찰서 · 총독부)의 장면을 정문부터 마지막까지 하나씩 돌파합니다.
- **주사위 하나 = 행동 하나.** 매일 아침 요원마다 작전 주사위를 굴립니다. 큰 눈을 멀리 가는 데 쓸지, 작전 판정에 남길지가 매 차례의 고민입니다.
- **압박은 셋입니다.**
  - 노출: 높을수록 경찰이 빨라진다
  - 일제 동향: 막지 못한 작전이 쌓인다
  - 오늘의 위협 카드
  
  시끄러운 일을 하면 경찰이 붙고, 따라잡히면 투옥됩니다.
- **혼자지만 협력 게임입니다.** AI 동료 셋이 주사위를 건네고, 같은 날 함께 장면을 돌파합니다.
- **개인 사연(비밀 목표).** 요원마다 남몰래 품은 사연이 있습니다. 결행의 성패와 사연을 이뤘는지에 따라 후일담이 네 갈래로 갈립니다.

## 기획 포인트

### 데이터 주도 설계
규칙 수치 · 카드 · 효과 · AI 판단 가중치, 그리고 카드 · 사연 · 엔딩 · 튜토리얼 문장은 모두 `game/data/v2/*.json`에 있고, **코드에 카드 id나 밸런스 · AI 수치를 쓰지 않습니다.** 새 카드는 JSON만 고쳐서 더하고, AI 성향도 JSON 값으로 조정해 밸런스 도구로 바로 잽니다. 일부러 코드에 남긴 것(효과 어휘의 실행, 엔진 기록 문장 등)은 이유와 함께 문서에 적었습니다. 검증기가 오타 · 모르는 효과 · 빠진 필드를 잡습니다. 파일별 열쇠와 더하는 법은 [데이터_구조.md](v2_구현/데이터_구조.md)

| 파일 | 담는 것 |
|---|---|
| `board.json` | 보드 크기 · 결행 거점 4곳(id · 칸 · 이름) · 지도 · 타일 그림 |
| `rules.json` | 주사위 수 · 판정 목표 · 경찰 속도 · 노출 단계 · 결행 조건 · 투표 통과 규칙 · AI 판단 가중치(성향 · 걷기 · 미션 가치 · 결행 혜택 등) |
| `missions.json` | 미션 22장 + 일제 작전 4장 (조건 · 마커 · 보상 · 보너스) |
| `threats.json` | 위협 카드 22장 (1막 14 · 2막 8) |
| `scenes.json` | 결행 거점 4곳의 장면 · 경비 강화 4장 |
| `characters.json` | 요원 12명 (특성 · 능력 · 대사) |
| `sagas.json` | 개인 사연 20장 + 결과별 후일담 |
| `events.json` · `items.json` · `endings.json` | 이벤트 10 · 아이템 10 · 엔딩 문장 |
| `ui.json` | 행동 단추 구성 · 미션 기본 그림 · 마커 글자 · 날씨 연출 · 훈련 할 일 |
| `online.json` | 온라인 서버 주소 · 시간 · 보안 상한 |

### 측정으로 맞춘 밸런스
`game/tools/v2_balance.gd`로 AI 4명 판을 1,000판씩 돌려 수치를 맞췄습니다. 그래프는 [밸런스 보고](portfolio/balance.html).
- 승률 **56.5%**(목표 50~55%, 다른 시드 54.9%) · 결행 대상별 승률 차이 **6%p**(목표 15%p 안, 다른 시드 10%p) · 요원별 차이 −4.1 ~ +6.3%p
- 엔딩 분포: 성공 565 · 2막 중간에서 멈춤 266 · 마지막 장면에서 멈춤 121 · 시간 끝 48 · **돌파율 70% 아래 장면 0개**(전에는 4개)
- 수치로 메우기 전에 원인을 확인했습니다. AI 작업 세션의 분석에서 일제 작전을 못 막는 원인이 기한이 아니라 AI가 마커를 쫓지 않는 데 있다고 나와, 수치 대신 AI를 고쳤습니다(28% → 60%).
- 점검에서 AI가 **성공 확률 0%인 판정**(낸 눈 1로 목표 10 등)을 판당 13.8번 하던 것을 찾아 고쳤습니다(4.2번, 남는 주사위는 동료에게: 건네기 5.1 → 8.6번). AI가 똑똑해지며 승률이 57.1%로 올라, 가장 높던 두 거점의 장면(총독부 근위대 · 군영 군견 판정 10 → 11)을 맞췄습니다. 자세한 것은 [점검 반영](v2_구현/점검_반영.md).
- **규칙 단순화**: 측정에서 거의 쓰이지 않던 군자금(82%의 판이 0으로 끝남) · 미끼(0번) · 아이템 건네기 · 구출을 뺐습니다. 행동 단추 11 → 8. 뺀 직후 승률이 59.4%로 올라 형무소 · 총독부 장면 판정을 한 칸씩 올려 맞췄습니다. 자세한 것은 [규칙 단순화](v2_구현/규칙_단순화.md).
- **재미 개선**: 측정에서 「재미없는 순간」을 찾아 규칙을 바꿨습니다. 투옥의 93%가 경찰 체포였고 차례의 20%가 탈옥 시도라 **갇히면 다음 날 아침 석방**으로(탈옥 시도 판당 7.4 → 0.3번), 2막 멈춤이 주사위 한 번에 거는 판정에 몰려 있어 **실패할수록 쉬워지는 「포위망」**과 **남긴 주사위 → 첩보 토큰**을 넣고 어려움은 시간(11 → 9일)으로 옮겼습니다. 사연 성공률은 9~89% → 26~60%, 쓰기 어렵던 정찰은 뺐습니다(단추 8 → 7). 자세한 것은 [재미 개선](v2_구현/재미_개선.md).

## 만든 방식
- **원안**: 게임 기획 학원 팀 과제 보드게임(4인 팀, 약 1주일). 저장소 주인이 팀장으로 콘셉트 · 실물 제작 · 룰 수정 · 설명서 작성, Tabletop Simulator 프로토타입. 지금 게임은 콘셉트만 이어받고 규칙과 구조를 새로 기획
- **기획 · 규칙 개정 · 지시서 · 검수 · 플레이 판단**: 저장소 주인
- **구현**: AI 코딩 도구(Claude Code)가 지시서를 받아 구현 · 시험 · 측정하고, 결과를 보고 문서로 남김
- **그림**: AI 이미지 생성(OpenAI)으로 만들고, 한 장씩 검토해 다시 생성(138장). 미션 카드별 그림 22장 포함. 그림체 기준은 사람이 골랐다. 자세한 기록은 [CREDITS](game/CREDITS.md)
- **소리 · 음악**: 코드로 직접 합성 (외부 음원 없음)

## 실행
- **Godot 4.7.1**에서 `game/project.godot`을 열고 F5
- 명령줄: `godot --path game`

### 시험
```bash
godot --headless --path game --script res://tests/v2_mechanics_test.gd   # 규칙 1,080개
godot --headless --path game --script res://tests/v2_ai_test.gd          # AI 220판 (멈춤 · 반칙 0)
godot --headless --path game --script res://tests/v2_net_test.gd         # 온라인 판 + 보안 시험
godot --headless --path game -- v2uitest 2                              # 화면으로 두 판 끝까지 (넘침 검사)
godot --headless --path game --script res://tools/v2_balance.gd -- games=1000   # 밸런스 측정
```

### 빌드
- 웹(itch.io): `powershell -ExecutionPolicy Bypass -File game\tools\build_web.ps1` → `build/web/`
- 온라인 서버: Render 무료 웹 서비스에 블루프린트(`render.yaml`)로 올린다. 소스를 Godot 헤드리스로 바로 돌린다. 순서는 [서버_배포.md](v2_구현/서버_배포.md)
