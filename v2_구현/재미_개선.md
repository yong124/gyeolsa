# 재미 개선 (2026-10-14)

> 「감옥 · 사연 · 2막은 지금 그대로면 재미없다. 남는 주사위도 고친다. 정찰은 쓰기 어렵고 필요 없다.」 (사용자 결정)
> 설계와 순서는 [지시서 S](지시서/S_재미_개선.md)에 있다. 여기에는 측정과 결과를 적는다. 모든 수치는 AI 4명 판(1,000판, 시드 610000 · 910000)이다.

## 1. 원인부터 쟀다
| 물음 | 측정 | 판단 |
|---|---|---|
| 왜 이렇게 자주 갇히나 | 투옥 원인의 **93%가 경찰 체포**(300판: 체포 1,522 · 그 밖 110). 한 번에 평균 1.9일 손해 | 고칠 곳은 「쫓기는 구조」다 |
| 수치로 줄일 수 있나 | 경찰 속도 `[2,3,4]→[2,2,3]` 5.5→4.9번, 따돌리기 · 출현 거리 4: 5.1번, 압수 0: 5.3번 | 안 된다. **잡히는 횟수가 아니라 잡혔을 때 잃는 것**을 줄인다 |
| 2막은 왜 멈추나 | 돌파율 70% 아래 장면 4개가 **모두 주사위 한 번에 거는 판정**. 합 · 인원 · 버티기 · 바치기 장면은 95~100% | 어려움이 운에만 몰려 있다 |
| 벽 하나 | 「당직 순사」 목표 13. 판정은 「낸 눈 + 1d6」이라 최대 12 → **첩보 토큰 없이는 0%** | 데이터 실수. 검증기로 다시는 못 들어오게 한다 |
| 주사위는 어디서 버려지나 | 버려진 주사위의 **56%가 2막**, 21%가 갇힌 요원 몫 | 2막에 「남김」의 쓸모를 준다 |

## 2. 바꾼 규칙
| 무엇 | 전 | 후 |
|---|---|---|
| 감옥 | 탈옥 판정(8)으로만 나옴, 아이템 1장 압수 | **다음 날 아침 석방**(밤에 잡히면 하루 더, 경찰 안 붙음). 탈옥은 「그날 바로 나가기」(성공하면 경찰이 붙음). **압수 없음** |
| 2막 판정 | 실패해도 그대로 | **포위망**: 같은 장면에서 실패하면 목표 −1(장면마다 한 번) |
| 2막 주사위 | 요원마다 3개, 남으면 사라짐 | 2개. **밤에 남긴 2개마다 첩보 토큰 1**(3개까지) |
| 정찰 | 행동 단추(덮인 칸을 좌표로 고름) | **뺌**. 덮인 칸은 걸어서만 뒤집힘. 단추 8 → 7 |
| 작전 일수 | 11일 | **9일** (어려움을 시간으로) |
| 경비 강화 | 경계 2단계부터 1장 | **늘 1장**(결행 혜택으로 뺄 수 있음) |
| 검증기 | — | 장면 판정 목표가 주사위 최대(12)를 넘으면 오류 |

| 뒷문 잠입 · 감방 수색 · 보초 교대 | 2명 → **3명**, 1명 → **2명** 버팀, 1명 → **2명** 버팀 |

## 3. 밸런스를 맞춘 과정
새 장치만 넣었더니 **승률 87%**였다. 하나씩 꺼 보며 원인을 나눴다(300판).

| 끈 것 | 승률 |
|---|---|
| 아무것도 안 끔 (판정 목표를 많이 낮춘 판) | 87% |
| 판정 목표를 원래대로(13만 12로) | 83% |
| + 포위망 끔 | 76% |
| + 토큰 끔 | 69% (감옥 석방만 남음: 63%) |

- 포위망과 토큰은 「벽을 없애는」 장치라 남겼다. 어려움은 **시간(9일)과 2막 주사위(3 → 2개), 포위망 −1 한 번, 경비 강화 늘 1장**으로 되찾았다.
- 결과로 실패의 모양이 바뀌었다. 전에는 「한 장면의 주사위 운」이었고, 지금은 「날이 모자람」이다. 2막 중간 멈춤은 34% → 27%다. 목표 20%에는 못 미쳤다.

## 5. 못 맞춘 것 · 사람 테스트에서 볼 것
- **승률이 목표 위쪽 끝**(55%)에 걸쳐 있다(56.5 / 54.9). 사람이 AI보다 잘하면 더 오른다. 사람 테스트 뒤 9일 → 8일(실험에서 49%) 사이에서 정한다.
- **2막 중간 멈춤 27%**: 이제는 벽이 아니라 시간이 원인이다. 실패 엔딩의 「돌파 n / m」 표시(지시서 3절 5번)는 아직 넣지 않았다.
- **동생의 원수 26~28%**: 30%에 조금 못 미친다.
- **일제 작전을 89% 막는다**(목표 50~70%, 전 61%). 감옥이 짧아져 요원이 덜 묶이고, 작전 기한은 그대로라 쉬워졌다. 기한이나 벌칙을 다시 본다.
- **강제 결행이 17%**(전 10%). 9일로 줄어 투표로 결행하기 전에 날이 차는 판이 늘었다.
- **아이템 사용**은 압수를 없애도 판당 1.3번 그대로다. 아이템을 「얻어도 쓸 데가 없음」은 따로 볼 문제다.
- **형무소 선택률 12~14%**: 승률은 맞췄지만 고르는 사람이 적다(범위 밖, 다음 지시서).
- AI의 2막 「남김」 판단(`leftover_value`)은 넣지 않았다. AI는 쓸모없는 주사위를 이미 억지로 쓰지 않는다(버려진 주사위 29%).
