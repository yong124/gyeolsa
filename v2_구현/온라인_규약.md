# 온라인 규약 (v2, 2026-10-08)

> 지시서 H1 · H2를 최소 구성으로 구현한 것이다. 설계 근거는 `12단계_평가_반영.md` 6절. 코드는 `game/scripts/net/`.

## 구조
- **서버 권위.** 서버가 `RulesV2`를 돌린다. 클라이언트는 행동만 보낸다. 판정 · 난수 · AI는 모두 서버에서 한다.
- 클라이언트는 서버가 보낸 **보기**(`NetViewV2.view_for`)를 로컬 `RulesV2.load_state()`로 읽어 **기존 게임 화면을 그대로** 그린다(연습 모드와 같은 화면 코드).
- 요원은 늘 4명. 사람이 없는 자리, 끊긴 지 20초가 지난 자리는 **서버 AI**(`GameAIV2`)가 둔다.
- 낮은 지금 규칙대로 **순서 자유, 한 번에 한 요원**(B단계 결정). 동시 낮(설계 6.1)은 하지 않았다.

## 실행
- 서버: `Godot --headless --path game -- server [port=8910]`
- 클라이언트: 타이틀 → 「온라인」 → 서버 주소(기본 `ws://127.0.0.1:8910`) · 이름 → 방 만들기 / 코드로 참가.

## 전송
- WebSocket(`WebSocketPeer` · `TCPServer`), 바이너리 패킷. 패킷 하나 = `var_to_bytes(Dictionary)` (객체 없음, Vector2i 그대로).
- 서버 → 클라이언트 패킷은 앞 1바이트가 방식이다(규약 2, Z5): `0` = 그대로, `1` = 원래 크기(u32) + zstd 압축. 512바이트보다 작으면 압축하지 않는다. `NetServerV2.pack()` / `unpack()`. 클라이언트 → 서버는 그대로 `var_to_bytes`.
- 작전 기록은 새 줄만 보낸다. 보기의 `log_from`은 앞서 받은 줄 수이고, `log_lines`는 그 뒤의 새 줄이다. 클라이언트는 갖고 있던 기록의 앞 `log_from`줄에 새 줄을 이어 붙인다. 시작 · 돌아오기는 `log_from = 0`(전부).
- 메시지 종류는 `t`.

## 클라이언트 → 서버
| t | 내용 |
|---|---|
| `hello` | `name`, `ver`(=2), `token`(다시 붙을 때 받은 토큰) |
| `create` | 방 만들기 (만든 사람이 방장, 자리 0) |
| `join` | `code` (대문자 · 숫자 5자, 0 O 1 I 없음) |
| `pick` | `character`: 받은 두 장 중 하나 |
| `ready` | `on` |
| `start` | 방장만. 사람은 모두 요원을 골라야 함 |
| `act` | `a`: 엔진 행동 사전. `player`는 내 자리여야 함. `start_day`는 「준비」로 받아 **사람이 모두 누르면** 시작(60초가 지나면 자동) |
| `leave` | 방 나가기 (판 중이면 그 자리는 바로 AI) |

## 서버 → 클라이언트
| t | 내용 |
|---|---|
| `welcome` | `token` (다시 붙을 때 씀) |
| `room` | `code`, `host`, `you`(내 자리), `seats`[4]: `name`, `human`, `ready`, `character`, `offer`(내 자리만), `online` |
| `start` | `seat`, `view`, `names` |
| `update` | `view`, `events`(연출, 남의 비밀 이벤트는 뺌), `info`: `waiting_day`(아침에 아직 안 누른 자리), `ai`(AI가 맡은 자리) |
| `error` | `msg` |

## 숨기는 것 (`NetViewV2`)
- 다른 사람의 **이루지 않은 사연**(id → `?`), 사연 더미, 남길 사연 · 위협 덱 보기 선택 창의 보기 값
- **덱 순서**: 타일 · 미션 · 이벤트 · 아이템 · 일제 작전 덱과 버린 더미(장수만), 위협 덱(요원들이 미리 볼 수 있는 장수만 남김)
- **공개 전 투표**(낸 사람만, 무엇을 냈는지는 `?`)
- 난수 상태, 행동 기록(선택 값이 들어 있음)
- 판이 끝나면 후일담에서 모두의 사연을 함께 본다(의도된 공개).

## 시간 · 끊김
- AI 한 수 간격 0.45초(사람이 따라 볼 수 있게).
- 사람 자리가 150초 동안 아무것도 안 하면 서버가 AI로 한 수를 대신 둔다(판이 멈추지 않게).
- 끊기면 20초 뒤 AI가 맡고, 같은 토큰으로 돌아오면 자리를 돌려받는다(전체 보기를 다시 받음).
- 사람이 모두 나간 방은 2분 뒤 닫는다.

## 시험
- `tests/v2_net_test.gd`: 서버 + 사람 클라이언트 2명(자기 보기만 보고 AI로 둠) + 서버 AI 2명. 판 끝까지 · 받은 모든 보기의 비밀 누출 검사 · 남의 자리 행동 거절 · 끊었다 다시 붙기.
- `tools/tour.gd online`: 실제 로비 화면 → 방 → 판 끝까지(화면 쪽 사람 + 가짜 친구 1명) 캡처.

## 하지 않은 것 (설계에는 있음)
- 동시 낮 · 낮 제한 시간 · 칸 찍기 · 주사위 찜 · 빠른 말 · 군자금 승인 · 동시 비공개 투표 연출
- 「같은 방에서 다시」(지금은 새 방), 다시보기 저장
- **배포**: 서버를 늘 켜 둘 곳이 필요하다. 웹판(https의 itch.io)에서 붙으려면 서버가 **wss://**(TLS)여야 한다. 데스크톱판은 ws://로 된다.

## 공개 방 목록 (2026-10-08)
- `create`에 `name`(16자, 서식 문자는 걸러짐 · 비우면 「<이름>의 작전」)과 `public`(기본 true)을 더했다. 비공개 방은 목록에 안 나오고 코드로만 들어온다.
- `list` → `rooms`: 아직 시작하지 않았고, 공개이고, 사람이 1~3명인 방만 보낸다(최대 50개). `{"code", "name", "humans", "max"}`.
- `room` 메시지에 `name` · `public`을 더했다.
- 시작 조건: 사람은 모두 요원을 골라야 하고, 방장을 뺀 사람은 모두 「준비」를 눌러야 한다. 방장 혼자면 바로 시작할 수 있다(빈자리는 AI).
- 화면: 방 고르기에서 방 이름 · 공개/비공개 · 방 만들기, 공개 방 목록(4초마다 새로 받음, 「참가」), 코드로 참가.
- 시험(`v2_net_test`): 방 이름(서식 걸러짐) · 공개 방이 목록에 보임 · 비공개 방은 안 보임 · 모두 준비해야 시작 · 시작한 방은 목록에서 빠짐.
