# 온라인 서버 배포 (Fly.io) — 웹판에서 친구와 하기

> 계정 · 결제 · 배포는 직접 한다. 여기 있는 명령은 PowerShell 기준이다.
> 구조: 브라우저(itch.io, https) → `wss://<앱>.fly.dev` → Fly가 TLS를 풀어 → 컨테이너 안 Godot 헤드리스 서버(8910, ws)

## 0. 준비물 (이미 저장소에 있음)
- `deploy/server/Dockerfile`: debian-slim + 서버 실행 파일. 일반 사용자 권한으로 돈다.
- `deploy/server/fly.toml`: 앱 이름 `gyeolsa-server`, 도쿄 리전, 늘 켜 둠, 256MB.
- `game/tools/build_server.ps1`: 리눅스 헤드리스로 내보내 `build/server/`에 Dockerfile · fly.toml과 함께 둔다.
- `game/data/v2/online.json`: 서버 주소 · 포트 · 시간 · 보안 상한.

## 1. 서버 빌드
```powershell
powershell -ExecutionPolicy Bypass -File game\tools\build_server.ps1
```

## 2. Fly.io 가입과 도구 설치 (한 번만)
```powershell
iwr https://fly.io/install.ps1 -useb | iex
fly auth signup
```
요금: 가장 작은 기계(shared-cpu-1x, 256MB)를 늘 켜 두면 한 달 몇 달러 안팎이다. 가입할 때 카드 등록이 필요할 수 있다. 최신 요금은 Fly.io 요금 페이지에서 확인한다.

## 3. 배포
```powershell
cd build\server
fly launch --no-deploy --copy-config --name gyeolsa-server   # 이름이 이미 있으면 다른 이름
fly deploy
```
주소는 `wss://<앱 이름>.fly.dev`가 된다.

## 4. 게임에 주소 넣고 웹판 다시 빌드
1. `game/data/v2/online.json`의 `"server_url_web"`을 `"wss://<앱 이름>.fly.dev"`로 바꾼다.
2. 웹판을 다시 빌드한다. 이 주소가 들어 있어야 웹판 타이틀에 「온라인」이 보인다.
   ```powershell
   powershell -ExecutionPolicy Bypass -File game\tools\build_web.ps1
   ```
3. itch.io에 새 zip을 올린다.

## 5. 확인
- 브라우저 두 개(또는 친구)로 itch.io 페이지 → 온라인 → 방 만들기 → 코드로 참가 → 시작
- 서버 기록: `fly logs` (`[server] 방 ABCDE 만듦` 같은 줄)
- 끄기: `fly scale count 0` (돈이 들지 않게) · 다시 켜기: `fly scale count 1`

## 보안 메모 (지시서 Z1)
- 토큰은 128비트 암호 난수로 만든다. 접속 256, 방 128, 연결당 초당 메시지 30을 넘지 못한다. 방 코드를 10번 틀리면 끊는다. 이름의 서식 문자는 걸러진다.
- 상한 값은 `online.json`의 `limits`에서 바꾼다.
- 서버는 판 상태를 메모리에만 둔다. 다시 배포하거나 재시작하면 진행 중인 방이 사라진다.
