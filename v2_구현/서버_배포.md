# 온라인 서버 배포 (Render 무료) — 웹판에서 사람끼리 하기

> 계정 만들기 · 배포 클릭은 직접 한다. 카드 등록은 필요 없다(무료 플랜).
> 구조: 브라우저(itch.io, https) → `wss://<서비스>.onrender.com` → Render가 TLS를 풀어 → 컨테이너 안 Godot 헤드리스 서버(ws, 포트는 Render가 `PORT`로 정해 줌)

## 0. 저장소에 이미 있는 것
- `render.yaml`: Render 블루프린트. 무료 웹 서비스 `gyeolsa-server`, 싱가포르 리전, `v2` 브랜치, 푸시하면 자동 배포.
- `deploy/render/Dockerfile`: Godot 4.7.1 리눅스판을 받아 `game/` 소스를 그대로 서버로 돌린다. 내보내기(빌드)를 따로 할 필요가 없다.
- `.dockerignore`: 이미지에는 `game/`만 넣는다.
- 서버는 환경 변수 `PORT`가 있으면 그 포트에서 듣는다(`main.gd`). 없으면 `online.json`의 `port`.

## 1. Render에 올리기 (한 번만)
1. https://render.com 에서 **GitHub 계정으로 가입**한다.
2. 대시보드 → **New → Blueprint** → GitHub 연결 허락 → 저장소 `yong124/gyeolsa` 고르기.
3. Render가 `render.yaml`을 읽어 `gyeolsa-server`를 보여 준다 → **Apply**.
4. 첫 빌드는 몇 분 걸린다(Godot 받기 + 리소스 가져오기). 로그에 `[server] 서버 시작 · 포트 10000 · ok` 같은 줄이 나오면 된다.
5. 서비스 페이지 위쪽의 주소 `https://gyeolsa-server-xxxx.onrender.com`을 복사한다. 게임에서 쓸 주소는 앞을 `wss://`로 바꾼 것이다.

## 2. 게임에 주소 넣고 웹판 다시 빌드
1. `game/data/v2/online.json`의 `"server_url_web"`을 `"wss://gyeolsa-server-xxxx.onrender.com"`으로 바꾼다.
2. 웹판을 다시 빌드한다. 이 주소가 있어야 웹판 타이틀에 「온라인」이 보인다.
   ```powershell
   powershell -ExecutionPolicy Bypass -File game\tools\build_web.ps1
   ```
3. itch.io에 새 zip을 올린다.

## 3. 무료 플랜의 성질
- **잠듦**: 15분 동안 아무 접속이 없으면 서버가 잠든다. 판 중에는 메시지가 오가므로 잠들지 않는다.
- **깨우기**: 잠든 뒤 첫 접속은 서버가 깨는 데 1분쯤 걸린다. 게임은 이 동안 「서버를 깨우는 중… (N초)」를 보이며 3초마다 다시 붙는다(최대 `online.json`의 `wake_wait`, 기본 90초). 응답 없는 시도는 10초에서 끊고 다시 한다.
- **상태는 메모리에만**: 다시 배포하거나 서버가 잠들면 진행 중이던 방은 사라진다.
- 한 달 무료 시간(750시간)은 서비스 하나를 늘 켜 둬도 넘지 않는다.

## 4. 확인
- 브라우저 두 개(또는 친구)로 itch.io 페이지 → 온라인 → 방 만들기 → 코드로 참가 → 시작
- 서버 기록: Render 서비스 페이지 → **Logs** (`[server] 방 ABCDE 만듦` 같은 줄)
- 코드를 `v2`에 푸시하면 서버도 자동으로 다시 배포된다(그동안 진행 중인 방은 끊긴다).

## 보안 메모 (지시서 Z1)
- 토큰은 128비트 암호 난수로 만든다. 접속 256, 방 128, 연결당 초당 메시지 30을 넘지 못한다. 방 코드를 10번 틀리면 끊는다. 이름의 서식 문자는 걸러진다.
- 상한 값은 `online.json`의 `limits`에서 바꾼다.

## 다른 호스팅
`deploy/server/Dockerfile`은 내보낸 리눅스 실행 파일(`game\tools\build_server.ps1`)을 담는 이미지다. Render 말고 다른 곳(VM 등)에 올릴 때 쓴다.
