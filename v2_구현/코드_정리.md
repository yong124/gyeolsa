# 코드 정리 (2026-10-13)

> 코드를 평가해 보니 동작에는 문제가 없었습니다. 시험 6종이 모두 통과했고, 성능도 넉넉했습니다(합법 액션 평균 52~119µs, 온라인 패킷 압축 후 약 2.5KB). 대신 커지면서 생긴 구조 문제, 그리고 README가 하는 주장과 실제 코드가 어긋나는 곳이 있었습니다. 이번 정리는 **게임 동작을 하나도 바꾸지 않는 것**을 조건으로 했습니다. 예외는 저장 버전 확인 하나입니다.

## 1. 동작이 그대로인지 확인한 방법
판은 결정론적입니다. 같은 시드에 같은 액션이면 같은 판이 나옵니다. 그래서 정리 전에 밸런스 도구로 AI 4명 판 300판(`seed=777000`)을 돌려 결과를 떠 두었습니다. 단계마다 같은 측정을 다시 돌려, **출력과 결과 JSON이 출력 경로 한 줄만 빼고 한 글자도 다르지 않은지** 비교했습니다. 엔진 분할, 화면 멤버 이름 바꾸기, AI 수치 옮기기 세 단계 모두 같았습니다.

## 2. 바꾼 것

| 문제 | 정리 |
|---|---|
| 규칙 엔진 `rules_v2.gd` 한 파일이 5,265줄(함수 326개) | 층마다 한 파일로 나눔. 위 층이 아래 층을 상속합니다: `rules_base_v2`(상태 · 조회 · 판정 함수 · 저장, 1,068줄) → `rules_effects_v2`(효과 해석기 · 경찰 · 아이템, 1,333) → `rules_missions_v2`(547) → `rules_saga_v2`(결행 · 사연, 627) → `rules_act2_v2`(2막 · 엔딩, 499) → `rules_v2`(초기화 · apply · 하루 흐름 · 이동 · 판정, 1,290). 바깥에서는 여전히 `RulesV2` 하나만 씁니다 |
| 나눈 층끼리 서로 부르는 곳 | 호출 관계를 분석해, 위 층으로 거슬러 부르는 함수가 가장 적은 배치를 골랐습니다(45개 → 12개). 남은 12개는 `rules_base_v2.gd` 맨 끝의 「위 층이 채우는 고리」에 자리를 잡아 두고, 위 층이 같은 모양으로 덮어씁니다 |
| 규칙 시험 한 파일이 5,341줄 | `tests/mechanics/`에 층마다 한 파일(기본 규칙 · 카드 · 사연 · 2막 · 행동 경제 · 미션). 실행은 그대로 `v2_mechanics_test.gd`. 옮기다 빠진 줄이 0줄인지 줄 단위로 대조했습니다 |
| 화면 모듈이 화면의 사적 멤버(`scr._…`)를 286번 직접 건드림 | 함께 쓰는 멤버 69개를 공개 이름으로 바꿈. 지역 변수와 겹치는 이름은 뜻이 드러나는 이름을 새로 붙였습니다(`_text` → `text_mod`, `_board` → `board_view`, `_fx` → `fx_layer`, `_act` → `send_action` 등). 약속: 밑줄 없는 멤버는 모듈과 함께 쓰는 것이고, 밑줄 멤버는 화면 안에서만 씁니다. 사적 접근은 0번이 되었습니다 |
| README는 「코드에 밸런스 수치를 쓰지 않는다」고 하지만, AI 점수 상수가 `ai_v2.gd`에 박혀 있었음 | AI 판단 수치 약 50개를 `rules.json`의 `ai`로 옮김: `turn_order` · `walk` · `mission`(종류별 배수) · `benefit`(결행 혜택, 효과 op별) · `effect_choice` · `morning` · `scout_first` · `intel_trade` · `saga_keep` · `saga_progress` · `strike_pick` 등. 코드에 남은 숫자는 동점 깨기뿐입니다. 이제 `set=ai.walk.danger=6`처럼 AI 성향을 밸런스 도구로 바로 잴 수 있습니다. 검증기가 빠진 열쇠를 잡습니다(`AI_KEYS`, 자체 시험 2개 추가) |
| 엔진 기록 문장 · 화면 문구는 여전히 코드에 있음 | 상태 값을 끼워 넣어 만드는 문장이라 코드에 남깁니다. 대신 README의 주장을 정확히 고치고, [데이터_구조.md](데이터_구조.md) 6절 「일부러 코드에 남긴 것」에 이유를 적었습니다 |
| 저장에 게임 버전이 없음. 2.2.0에서 위협 카드 `fund_freeze`가 빠졌는데, 2.1 저장에서 그 카드가 뒤집히면 이름 대신 id가 뜨고 효과가 조용히 사라짐 | 저장에 게임 버전(`application/config/version`)을 적습니다. 버전이 다른 저장은 이어 하지 않고, 첫 화면에 「게임이 새 버전(2.2.0)으로 바뀌어, 2.1.0에서 하던 판은 이어 할 수 없습니다.」라고 알립니다. 쓰기는 임시 파일에 쓴 뒤 이름을 바꿔서, 쓰다가 끊겨도 원래 저장이 깨지지 않습니다. 시험 6개를 추가했습니다 |
| 규칙 단순화 뒤에 남은 흔적 | `missions.json` 설명 주석의 `gear`(군자금) · `informer_cost`, 쓰이지 않는 미끼 아이콘 2장, 주석의 「미끼」, 엔진 시험의 「미구현」 계측 3종(늘 0)을 「알 수 없는 효과」 하나로 |
| README의 시험 수가 낡음(1,152) | 1,056개로 고침 |
| 깃허브에서 시험이 돌지 않음 | `.github/workflows/tests.yml`: 밀어 올릴 때마다 Godot 4.7.1 헤드리스로 시험 7종을 돌립니다. README 맨 위에 배지를 달았습니다 |
| 웹판이 엔진보다 먼저 받는 시작 그림이 1.48MB | 256색으로 줄여 0.64MB. 눈으로는 구별되지 않습니다 |

## 3. 하지 않은 것
- **웹판 엔진 크기(39.5MB)**: 2D만 쓰므로 3D · 물리를 끈 맞춤 내보내기 템플릿을 만들면 크게 줄어듭니다. 다만 Godot을 소스에서 직접 빌드해야 해서(emscripten · scons) 이번에는 하지 않았습니다.
- **엔진 기록 문장의 데이터화**: 위 표의 이유대로 하지 않았습니다.
