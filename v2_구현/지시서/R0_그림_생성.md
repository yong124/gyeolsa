# 지시서 R0: 그림 원본 92장 만들기 (Codex용)

> 이 작업은 **그림 원본만** 만든다. 게임 코드·데이터·규칙은 건드리지 않는다. 게임에 넣는 일은 `R_그림.md` 2부(다른 작업)다.
> 목록과 의도는 `v2_구현/지시서/R_그림.md`, 프롬프트 92장은 `v2_구현/그림_프롬프트_GPT.md`에 있다.

## 준비물 (이미 있음)
- 기준 그림: `그림_원본/char/yun.png` (001 윤 소위, 사용자가 고름). **바꾸거나 다시 만들지 마라.**
- 생성 스크립트: `game/tools/gen_art.py`
  - 프롬프트 파일을 읽고, 매 장 기준 그림을 함께 보내(`images.edit`) 그림체를 맞춘다.
  - 결과는 `그림_원본/{폴더}/{id}.png`. 이미 있는 파일은 건너뛴다.
  - 기록은 `그림_원본/_log.jsonl`.
- `그림_원본/`은 `.gitignore`에 있다. **원본 PNG를 커밋하지 마라.**

## 할 일
1. 환경 확인: `OPENAI_API_KEY`가 있는지 확인한다. 없으면 멈추고 보고한다(키를 만들거나 묻지 마라). `pip install openai pillow`.
2. 목록 확인: `python game/tools/gen_art.py --list` → 92줄, 001만 「있음」이어야 한다.
3. **시험 3장:** `python game/tools/gen_art.py --only 2,13,25` (초상 · 미션 · 거점 하나씩). `--sheet`로 모아 보고 아래 「검수」를 한다. 그림체가 기준과 크게 다르면 멈추고 보고한다.
4. **1순위:** `--only 1-33` → `--sheet` → 검수 → 불합격은 `--only 번호 --redo`로 다시(한 번호에 최대 3번).
5. **2·3순위:** `--only 34-92` → 같은 방식.
6. 거절(안전 정책)된 번호는 프롬프트를 고치지 말고 목록으로 보고한다. 사용자가 프롬프트를 고친다.

## 검수 (그림마다 직접 열어 본다)
불합격이면 다시 만든다:
- 그림 안에 **글자 · 숫자 · 서명 · 로고**가 있다
- **욱일기**(붉은 햇살 무늬)가 있다
- 사진 같거나 3D · 애니메이션풍이다(목판화 결이 아님)
- 피 · 상처 · 시신이 보인다
- 초상: 얼굴이 위쪽 가운데에 있지 않거나 머리가 잘렸다
- 미션 · 일제 작전: 물건이 작아서 40px로 줄이면 알아볼 수 없다
- 프롬프트의 대상과 다르다(예: 여성이어야 하는데 남성)

## 설정
- 모델: 기본 `gpt-image-1`. 계정에 더 새 이미지 모델이 있으면 `--model` 또는 환경 변수 `ART_MODEL`로 바꿔도 된다(바꿨으면 보고에 적어라).
- 품질: 기본 `high`. 비용(대략): high는 장당 $0.17~0.25라 91장에 $20~25 안팎, `--quality medium`이면 그 1/4쯤. 사용자가 따로 말하지 않았으면 high로 한다.
- 한 번에 한 장씩, 순서대로 만든다(스크립트가 그렇게 한다). 병렬로 돌리지 마라.
