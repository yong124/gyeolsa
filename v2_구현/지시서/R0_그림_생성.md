# 지시서 R0: 그림 원본 92장 만들기 (Codex용)

> 이 작업은 **그림 원본만** 만든다. 게임 코드·데이터·규칙은 건드리지 않는다. 게임에 넣는 일은 `R_그림.md` 2부(다른 작업)다.
> 목록과 의도는 `v2_구현/지시서/R_그림.md`, 프롬프트 92장은 `v2_구현/그림_프롬프트_GPT.md`에 있다.
> **API 키는 쓰지 않는다.** 너(Codex)의 이미지 생성 기능으로 한 장씩 만든다.

## 준비물 (이미 있음)
- **기준 그림:** `그림_원본/char/001_윤_소위.png` (001 윤 소위, 사용자가 고름). **바꾸거나 다시 만들지 마라.** 모든 그림의 그림체 기준이다.
- **도우미 스크립트** `game/tools/gen_art.py` (API를 부르지 않는 기능만 쓴다. `pip install pillow`)
  - `--next 1`: 아직 없는 다음 그림 1장의 **번호 · 완성 프롬프트 · 크기 · 저장 경로(save_to) · 투명 여부**를 JSON으로 준다.
  - `--check`: 만든 그림의 비율 · 투명 배경을 확인한다.
  - `--sheet`: 만든 그림을 한 장에 모은다(`그림_원본/_sheet.png`).
  - `--list`: 92장 목록과 있음/없음.
- `그림_원본/`은 `.gitignore`에 있다. **원본 PNG를 커밋하지 마라.**

## 할 일
0. 먼저 네 이미지 생성 기능이 **참고 그림 첨부(기준 그림)** 와 **크기(1024×1536 · 1536×1024 · 1024×1024)** 를 받는지 확인한다. 이미지 생성 기능이 없으면 멈추고 보고한다.
1. `python game/tools/gen_art.py --list` → 92줄, 001만 「있음」.
2. 한 장씩 되풀이한다:
   1. `python game/tools/gen_art.py --next 1` 로 다음 그림을 받는다.
   2. **기준 그림(`reference`)을 참고 이미지로 첨부**하고, `prompt`를 **고치지 말고 그대로** 써서, `size` 크기로 만든다. `transparent`가 true면 투명 배경 PNG로 만든다.
   3. 결과를 `save_to` 경로에 **PNG**로 저장한다(폴더가 없으면 만든다).
   4. 저장한 그림을 직접 열어 아래 「검수」를 한다. 불합격이면 지우고 다시 만든다(한 번호에 최대 3번). 3번 다 불합격이면 가장 나은 것을 남기고 보고 목록에 적는다.
3. 순서: **먼저 3장만**(002 · 013 · 025가 나오도록 `--only 2,13,25 --next 1`을 써도 된다) → `--sheet`로 보고 그림체가 기준과 맞는지 확인 → 맞으면 001~033(1순위) → 034~092.
   - 3장 시험에서 그림체가 기준과 크게 다르면 **멈추고 보고한다.**
4. 10장마다 `--check`와 `--sheet`를 돌려 결이 흔들리지 않는지 본다. 흔들리면 기준 그림을 다시 첨부해 그 묶음을 다시 만든다.
5. 거절(안전 정책)된 번호는 프롬프트를 고치지 말고 목록으로 보고한다. 사용자가 프롬프트를 고친다.

## 검수 (그림마다 직접 열어 본다)
불합격이면 다시 만든다:
- 하늘이나 사람 뒤에 **붉은 동그라미(해 · 달 · 원)** 가 있다
- 초상끼리 **얼굴이 닮았다**(`--sheet`로 001~012를 나란히 놓고 본다)
- 그림 안에 **글자 · 숫자 · 서명 · 로고**가 있다
- **욱일기**(붉은 햇살 무늬)가 있다
- 사진 같거나 3D · 애니메이션풍이다(기준 그림처럼 새긴 선 · 빗금 · 바랜 종이가 아님)
- 피 · 상처 · 시신이 보인다
- 초상(001~012): 얼굴이 위쪽 가운데에 있지 않거나 머리가 잘렸다. 기준 그림의 **사람 · 군복을 그대로 베꼈다**(그림체만 따라야 함)
- 미션 · 일제 작전(013~023): 물건이 작아서 40px로 줄이면 알아볼 수 없다
- 프롬프트의 대상과 다르다(예: 여성이어야 하는데 남성, 노인이어야 하는데 청년)
- `--check`에서 비율이 다르다고 나온다
