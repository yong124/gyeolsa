> 먼저 `v2_구현/지시서/00_공통.md`를 읽어라. 앞 단계: **T 튜토리얼**(지금의 레슨형, 커밋 fcc487c · ba9c4db · 6132e24)이 끝나 있다. 이번에 그걸 고쳐 쓴다.
> 사용자 결정 (2026-10-12): 「지금은 정보만 과다다. 최대한 쉽게, 단계를 나누고, 행동을 보여 주며 알려 줘야 한다.」

## 1. 왜 고치나 (지금 상태를 세어 본 것)
| 문제 | 지금 |
|---|---|
| 읽기만 하는 단계가 절반 | 53단계 중 27단계가 「다음」만 누름. 첫 레슨 8단계는 전부 읽기 |
| 해 보기 전에 목록부터 | 미션 6종, 타일 8종, 행동 8개, 경찰 떨치는 법 3가지를 말풍선 하나에 나열 |
| 따라 누르기만 함 | 「하루 시작을 누르세요」, 「차례 마치기를 누르세요」가 대부분이라 고를 게 없음 |
| 말로만 설명 | 「경찰이 2칸 다가옵니다」를 글로만 쓰고 실제로 다가오는 걸 보여 주지 않음 |
| 한 번에 다 함 | 10레슨을 쉼 없이 이어 하고, 중간에 끝났다는 느낌이 없음 |
| 실전 안내도 길다 | `screen_coach_v2.gd`의 `TRAINING_STEPS` 안내가 한 개에 100~200자 |

## 2. 원칙 (이번 지시서에서 가장 중요)
1. **먼저 해 보고, 그다음 한 줄 설명.** 「이동해 보세요」 → (해 봄) → 「방금 ○○했어요. 그래서 △△예요.」
2. **말풍선 하나 = 개념 하나.**
   - 길이: **두 줄, 공백 포함 60자 이하**
   - 목록, 괄호 설명, 「~ · ~ · ~」 나열은 금지
   - 숫자는 지금 쓰는 것만 쓴다
3. **보여 주고 말한다.** 경찰이 다가오는 장면이나 동료가 성공하는 장면을 **연출이 끝난 뒤**에 말풍선으로 풀어 준다.
4. **작은 선택을 한다.** 「5와 2 중 어느 눈으로 판정할까?」처럼 고르게 하고, 틀린 쪽을 고르면 막지 말고 **이유를 알려 준 뒤 다시 고르게** 한다.
5. **잘게 나눈다.** 훈련 4개, 하나에 2~3분이다.
   - 하나가 끝날 때마다 「완료」 화면과 「배운 것 3줄」을 보여 준다.
   - 훈련 1만 하고 바로 실전으로 가도 된다.
6. **나머지는 실전에서 처음 나올 때.** 일제 작전, 검문소, 투옥, 군자금, 반격 같은 것은 첫 판에서 처음 나오는 순간 한두 줄로 알려 준다(7절). 목록 같은 정보는 「?」 도움말로 뺀다(8절).
7. **말투는 해요체**로 쓴다(「~하세요」, 「~했어요」). 버튼 이름은 화면 글자와 똑같이 「」에 넣는다.
8. **「다음」만 누르는 말풍선은 훈련마다 3개까지.** 할 일을 하면 바로 결과 한 줄로 반응한다.

## 3. 바꿀 구조
- **훈련 단위:** `tutorial.json`의 `lessons`를 **훈련 4개**(`trainings`)로 바꾼다. 훈련마다 다음을 둔다.
  - `id`, `title`, `goal`(한 줄 목표), `learned`(배운 것 3줄), `steps`
  - 각 훈련은 **새 판에서 시작**한다(시드 · 요원 · 판을 훈련마다 정함). 앞 훈련 결과에 기대지 않는다.
- **진행 저장:** `Prefs`에 훈련별 완료 여부를 둔다. 지금 `v2_training_done`은 「훈련 1 완료」로 바꾸거나 함께 쓴다.
- **메뉴:**
  - 「튜토리얼」 카드를 누르면 **훈련 목록**(카드 4장, 완료하면 ✔)이 나온다.
  - 처음 켜면 **훈련 1만** 바로 시작한다. 건너뛰기는 지금처럼 둔다.
- **완료 화면:**
  - 내용: 훈련 제목 + 「완료!」, 배운 것 3줄
  - 단추: 「다음 훈련」 · 「실전 시작」 · 「메뉴로」
  - 훈련 4를 마치면 「다음 훈련」 대신 「실전 시작」을 크게 둔다.
- **위쪽 머리글:** 「튜토리얼 3/10 · …」 대신 「훈련 1 · 첫 하루 · 2/12」처럼 지금 훈련 안에서의 진행만 보여 준다.

### 새로 필요한 기능 (`tutorial_v2.gd`, 엔진은 최소한)
| 기능 | 쓰는 곳 | 방법 |
|---|---|---|
| **굴림 정해 두기** | 판정이 꼭 성공하게, 아침 주사위 눈 정하기 | RulesV2에 `rigged_rolls: Array`를 두고, `_roll_die()`가 비어 있지 않으면 앞에서 꺼내 쓴다. 튜토리얼만 넣는다. 저장 · 시험에서는 비어 있어야 한다. setup op `rig` (`values: [4]`) |
| **주사위 개수 정확히** | 훈련 3에서 내 주사위를 6 하나만 | setup op `dice`에 `exact: true` (남는 주사위는 지운다) |
| **공작 진행 미리 채우기** | 훈련 1에서 「4 · 6은 동료가 이미 바침」 | setup op `work_paid` (`id`, `values: [4, 6]`) |
| **보기 단계** | 경찰이 다가오는 것, 동료의 성공을 보고 난 뒤 설명 | `do: "watch"`: 연출이 끝나고(`scr._playing` false) `when` 조건이 맞으면 말풍선과 「다음」. 조건에 `event`(그 단계 시작 뒤 엔진 이벤트 종류가 나왔는지, 예: `police_move`, `mission_done`, `check`)를 더한다 |
| **동료 대본** | 훈련 3에서 동료가 내가 준 6으로 판정 | 단계에 `ally: {"who": 1, "do": "mission_check", "die": 6}`. `ally_action()`이 그 단계에서 대본 행동을 먼저 낸다 |
| **고르기 + 되묻기** | 훈련 2의 판정 주사위 고르기 | 단계에 `pick: {"good": 5, "bad_say": "…"}`. 나쁜 눈을 누르면 행동을 넣지 않고 그 말풍선을 띄운 뒤 다시 고르게 한다(막는 게 아니라 알려 주기) |
| **훈련 끝** | 완료 화면 | `do: "complete"`: 완료 화면을 띄우고 진행을 저장한다 |

밝히기(Spotlight)와 말풍선 자리 잡기는 지금 것을 그대로 쓴다. 단, 말풍선 폭은 줄인다(글이 짧아지므로 360px 안팎).

- 「결사는 어떤 게임인가」 8단계 → 훈련 1의 첫 말풍선 하나
- 화면 구성 설명(동료 · 아래 독 · 요원 카드), 특성 · 능력 → 실전 첫 아침 안내 하나 + 도움말
- 미션 6종, 타일 8종, 행동 8개 목록 → 도움말
- 일제 위협 · 일제 작전 · 동향, 미끼, 면회 · 구출, 첩보 토큰, 반격, 후일담 → 실전 안내(7절)

## 6. 화면 다듬기
- 말풍선은 글자 17 → **18**로 키운다. 굵게 쓸 낱말 하나(예: **행동 하나**)는 강조색으로 칠한다(`[b]` 같은 간단한 표기를 데이터에 허용).
- 할 일 단계는 말풍선 아래에 작은 손가락 아이콘 + 「해 보세요」 꼬리표를 붙인다. 「다음」 단계와 구분되게 한다.
- 보기 단계는 화면을 어둡게 하지 않는다. 연출이 끝나면 그 자리만 밝힌다.
- 완료 화면: 종이 카드 + 도장 「완료」, 배운 것 3줄, 단추 3개.

## 7. 실전 첫 판 안내 (`screen_coach_v2.gd` 고쳐 쓰기)
- 지금 `TRAINING_STEPS`(13개, 100~200자)를 **처음 나올 때 한 번만 뜨는 짧은 쪽지**로 바꾼다.
  - **판을 멈추지 않는다.** 화면 가장자리에 뜨고, 7초 뒤나 클릭하면 사라진다.
  - 「자세히」를 누르면 도움말의 그 항목을 연다.
- 한 번 본 쪽지는 다시 안 띄운다(`Prefs`). 설정에서 끌 수 있다. 한 번에 하나만 띄우고, 나머지는 줄을 세운다.
- 문장(60자 이하)과 뜨는 때:

| 키 | 뜨는 때 | 문장 |
|---|---|---|
| first_morning | 실전 첫 아침 | 위쪽 붉은 카드는 오늘의 일제 위협이에요. 하루 동안 효과가 있어요. |
| saga | 첫 아침, 손패에 사연이 보일 때 | 사연은 나만 아는 개인 목표예요. 이루면 보상을 받아요. |
| ability | 첫 내 차례 | 내 요원의 능력은 하루 한 번, 주사위 없이 쓸 수 있어요. |
| op | 일제 작전 첫 등장 | 일제 작전이에요! 기한 안에 마커 칸에서 막아야 해요. |
| trend | 일제 동향이 처음 오를 때 | 못 막을수록 일제 동향이 올라 벌칙이 커져요. |
| checkpoint | 검문소가 처음 길을 막을 때 | 검문소는 들어갈 때 판정해요. 군자금 2로 뇌물도 돼요. |
| item | 아이템을 처음 얻을 때 | 아이템은 차례에 한 장, 주사위 없이 써요. |
| market | 장터 칸에 처음 설 때 | 장터에선 군자금으로 아이템을 살 수 있어요. |
| alert | 경계 단계가 처음 오를 때 | 노출이 쌓여 경계가 올랐어요. 경찰이 더 빨라져요. |
| jail | 처음 갇혔을 때 | 갇혔어요. 탈옥 판정을 하거나 동료가 구하러 와요. |
| ally_jail | 동료가 처음 갇혔을 때 | 동료가 갇혔어요. 그 거점에 들어가면 구해 낼 수 있어요. |
| lure | 동료가 처음 쫓길 때 | 「미끼」로 동료를 쫓는 경찰을 내 쪽으로 끌어올 수 있어요. |
| perk | 결행 혜택 창 | 준비가 3을 넘은 만큼 결행 혜택을 골라요. |
| intel_token | 2막 첫 판정 · 바치기 | 첩보 토큰은 판정 +1이나 바칠 합 −2로 써요. |
| counter | 반격이 처음 올 때 | 반격이에요! 자리에 선 요원이 판정 7로 막아야 해요. |

- 훈련을 마친 사람에게는 훈련에서 배운 키(이동, 판정, 숨기, 건네기, 결행)의 쪽지를 띄우지 않는다.
- 지금의 「훈련 할 일 상자」(U4)는 실전에서는 빼고, 훈련 안에서만 쓰거나 지운다. 무엇을 했는지 보고에 적어라.

## 8. 도움말 「?」
- 위쪽 띠에 「?」 단추를 둔다. 누르면 판을 멈추고 도움말 창을 연다. 탭 구성:
  - 행동 8개: 한 줄씩 + 주사위 눈이 중요한지
  - 미션 6종: 하는 법 한 줄씩
  - 타일: 그림 + 효과 한 줄
  - 판정: 작전 판정과 강제 판정, 확률 감
  - 경찰 · 노출 · 감옥
  - 결행 · 2막
- 문장은 `ui.json`이나 새 `help.json`에 데이터로 둔다. 규칙서(`docs/기획/결사_규칙서_v2.html`) 문장을 짧게 줄여 쓴다. 규칙서와 숫자가 다르면 데이터 값을 따른다.
- 이미 있는 규칙 요약 창이 있으면 그걸 도움말로 바꾼다. 두 개를 두지 마라.

## 9. 시험과 확인
- **검증기:** `tutorial.json`의 `say` 길이가 60자를 넘거나, 훈련마다 「다음」만 누르는 단계가 3개를 넘으면 실패하게 한다. 쪽지 문장도 같은 기준이다.
- **클릭 투어:** 훈련 4개를 각각 처음부터 끝까지 자동으로 누르는 투어를 고친다. 아래도 확인한다.
  - 훈련 2에서 **2를 먼저 고르는 길**(되묻고 다시 고름)
  - 건너뛰기, 중간에 메뉴로 나갔다가 다시 시작
  - 완료 표시 저장, 처음 켤 때 훈련 1만 뜨는지
- **굴림 정해 두기:** 튜토리얼이 아닌 판에서는 늘 비어 있고, 저장 파일에 들어가지 않는지 시험한다.
- **실전 쪽지:** 각 키가 조건에서 한 번만 뜨는지, 판을 멈추지 않는지(행동이 계속 되는지) 시험한다.
- **시간:** 훈련마다 사람 속도(말풍선 읽기 3초 + 클릭 1초로 어림)로 몇 분인지 재서 보고한다. 목표는 **각 3분 안**이다.
- **캡처:** tour로 각 훈련의 첫 말풍선, 고르기 되묻기, 보기 단계, 완료 화면, 실전 쪽지, 도움말을 찍어 직접 본다.
- 웹 빌드에서도 한 번 확인한다(말풍선 글꼴 서브셋에 새 글자가 빠지지 않았는지 확인하고, 빠졌으면 서브셋을 다시 만든다).
