# 지시서 G: 밸런스

> 먼저 `v2_구현/지시서/00_공통.md`를 읽어라. 앞 단계: **A·B·E·C·D**가 끝나 있어야 한다. F와는 순서가 상관없다.

## 읽을 것
1. 각 단계 문서 끝의 「구현 결과」: 단계마다 밸런스 전후가 적혀 있다.
2. `v2_구현/5단계_밸런스_결과.md`, `v2_구현/7단계_개인주사위.md`의 시뮬 절: 예전 측정 방법과 수치
3. `game/tools/v2_balance.gd`: 측정 도구
   - 옵션: `games=`, `seed=`, `players=`, `set=경로=값`, `sweep=경로=값1,값2`, `force_strike=`, `force_char=`, `data=`

## 목표 (2026-10-02 결정)
- **승률 50~60%** (사람 4명 기준). AI끼리는 사람보다 협력을 덜 하므로 **AI 4명 시뮬 45~55%**를 목표로 한다.
- 결행 대상별 승률 차이: **15%p 안**(지금 32~63%)
- 요원별 승률 차이(그 요원이 있는 판 기준): **10%p 안**
- 판 모양:
  - 결행은 1막 5~7일째에 대부분 일어난다.
  - 2막은 3~5일이다.
  - 일제 작전을 막는 비율은 50~70%다.
  - 「한 걸음이 모자랐다」 엔딩도 일정 비율 나온다(아슬아슬한 판).
- 2인·3인 방에서는 빈자리를 AI가 채우므로, 요원은 늘 4명이다. 사람 수에 따른 조정은 하지 않는다.

## 방법
1. **기준선:** `games=1000`으로 지금 수치를 측정한다. 시드를 고정해 둔다.
2. **원인 찾기:** 대상별, 요원별, 미션 종류별, 엔딩별로 나눠 본다. 승률이 크게 다른 곳은 판 기록(trace)을 몇 판 따라가 원인을 적는다.
3. **손잡이:** 데이터 수치만 바꾼다. 아래 순서로, 한 번에 하나씩 `sweep`으로 본다.
   - 장면 목표·합, 반격 목표, 결행 혜택 효과
   - 노출 증가 폭, 경계 단계 경계값, 경찰 이동, 따돌림 거리
   - 동향 벌칙 단계, 일제 작전 기한
   - 미션 보상, 기한, 지역
   - 군자금 값(시작, 장터, 뇌물, 매수)
   - 요원 특성·능력 수치
4. **규칙 자체를 바꿔야** 맞출 수 있다고 보이면 바꾸지 말고 보고의 「제안」에 적는다(예: 어떤 장면이 너무 운에 좌우됨).
5. **AI가 약해서** 생긴 차이(사람이면 쉽게 피할 실수)는 수치로 메우지 말고 AI를 고친다. 보고에 구분해서 적는다.

## 결과물
- 바꾼 수치는 데이터 JSON과 시험용 사본(fixture)에 반영하고, 깨진 시험의 기대값을 고친다.
- `v2_구현/12단계_밸런스_결과.md`를 새로 쓴다:
  - 기준선 → 최종 표(승률, 대상별, 요원별, 엔딩 분포, 판 모양 지표)
  - 바꾼 수치 목록(전 → 후, 이유)
  - AI를 고친 것
  - 남은 문제와 사람 플레이테스트에서 볼 것
- 규칙서 수치(본문, 부록, 요약 카드)를 바뀐 값으로 고친다.
