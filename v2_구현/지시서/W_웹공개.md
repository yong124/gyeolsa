# 지시서 W: 웹 공개 (itch.io)

> 먼저 `v2_구현/지시서/00_공통.md`를 읽어라. 앞 단계: **F 화면**, **G 밸런스**가 끝나 있어야 한다.

## 목표
채용 담당자가 링크를 누르면 **브라우저에서 바로, 설치 없이** 한 판을 시작할 수 있게 한다. 공개 장소는 **itch.io**(무료)다. 업로드는 사용자가 직접 한다. 너는 올릴 파일과 페이지 문구까지 준비한다.

## 읽을 것
- `game/tools/build_release.ps1`: 지금 Windows 빌드 스크립트. 테스트 → 내보내기 → 실행 확인 → 압축 순서다.
- `game/export_presets.cfg`
- Godot 4.7 웹 내보내기 문서. 확인할 것: 스레드 끄기 옵션, `user://`가 IndexedDB에 저장된다는 점, 오디오 자동재생 제한.

## 할 일
### 1. 웹 내보내기
- `export_presets.cfg`에 「Web」 프리셋을 더한다.
  - **스레드를 끈 단일 스레드 내보내기**로 한다. 그래야 itch.io에서 별도 헤더 설정(COOP/COEP) 없이 돈다.
  - 그래도 문제가 있으면 itch.io의 「SharedArrayBuffer support」 설정이 필요한지 보고한다.
- 내보내기 템플릿이 없으면 설치하지 말고 멈춘 뒤 보고한다. 설치는 다운로드라서 사용자가 해야 한다.
- 연습 모드 1인 + AI만 들어가게 한다. 개발용 진입점(tour, uitest, 디버그 메뉴)은 웹 빌드에서 빼거나 숨긴다.
- v1 화면이나 v1 데이터처럼 v2에 필요 없는 것이 빌드에 들어가는지 확인한다. 빼도 되면 내보내기 필터로 줄인다.

### 2. 크기와 로딩
- 처음 내려받는 크기를 잰다. 목표는 **30MB 안**이다.
- 한글 글꼴이 크면 **서브셋**을 만든다. 게임 안에서 쓰는 글자와 KS X 1001 한글 2,350자 정도로 줄이는 것을 검토한다. 글꼴 라이선스(OFL) 파일은 함께 둔다.
- 음악과 효과음은 압축 형식과 비트레이트를 확인한다.
- 로딩 화면: Godot 기본 로딩 바 대신 게임 색에 맞는 간단한 시작 화면을 쓴다. 로고는 쓰지 않는다.

### 3. 브라우저에서 확인할 것
- **오디오:** 첫 클릭 전에는 소리를 내지 않는다. 브라우저 자동재생 제한 때문이다.
- **저장과 이어하기:** `user://` 저장이 새로고침 뒤에도 남는지 확인한다.
- **화면 크기:** 1280×720, 1920×1080, 창 크기 바꾸기, 전체 화면 단추. 글자가 깨지거나 넘치지 않는지 본다.
- **입력:** 마우스 올리기(CardPeek), 오른쪽 클릭, 휠.
- **모바일:** 이번 범위가 아니다. 모바일로 들어오면 「PC 브라우저에서 해 주세요」 안내만 띄운다.
- **확인할 브라우저:** Chrome, Edge, Firefox. 첫 화면, 한 판 끝까지(AI 자동 진행으로 빠르게), 저장·이어하기를 본다.
- **성능:** 보드 그리기와 연출이 30fps 아래로 떨어지는 곳이 있는지 본다.

### 4. 첫 5분 (포트폴리오용)
- 첫 화면에서 **「바로 시작」 한 번**이면 판이 시작되게 한다. 요원과 설정은 기본값을 쓴다. 자세히 고르기는 따로 둔다.
- F단계의 첫 판 안내가 웹에서도 뜨는지 확인한다.
- 한 판 길이를 잰다. AI 자동 진행 속도가 아니라, 사람이 둔다고 보고 하루에 몇 분 걸리는지 어림한다. 그 값을 보고한다.

### 5. 빌드 스크립트
- `game/tools/build_web.ps1`을 만든다. 순서는 다음과 같다.
  1. v2 시험
  2. 웹 내보내기
  3. 로컬 서버로 띄워 헤드리스 확인(가능한 범위에서)
  4. itch.io용 zip(`index.html`이 최상위)
- 결과물은 `build/web/`과 `build/GwangbokIF_web_v<버전>.zip`이다.

### 6. itch.io 페이지 준비물 (`release/itch/`)
- 소개 문구(한국어):
  - 한 줄 소개
  - 게임 설명 3~4문단
  - 조작법
  - 한 판 길이
  - 크레딧
- 스크린숏 5장: tour로 캡처하고 1920×1080으로 맞춘다.
  - 첫 화면, 1막 보드, 행동 메뉴, 결행 투표, 2막 장면
- 짧은 GIF 1개: 하루 진행 10초 정도
- 업로드 설정 메모: 「This file will be played in the browser」, 뷰포트 크기, 전체 화면 단추, 「SharedArrayBuffer」 필요 여부
- **업로드, 계정, 결제 설정은 하지 마라.** 사용자가 직접 한다.

## 진행 (2026-10-08, 1차 · 템플릿 설치 전)
- **템플릿 없음.** `%APPDATA%\Godot\export_templates`가 비어 있어 내보내기는 멈췄다. 설치는 사용자 몫(다운로드)이다.
- **그림 압축:** 텍스처 180개를 무손실에서 손실(WebP, 품질 0.82)로 바꿨다. 내보낼 그림이 79.9MB에서 17.3MB로 줄었다. 데스크톱판에도 똑같이 적용된다.
- **글꼴:** Noto Sans/Serif KR 가변 글꼴 2개가 34MB다(가져온 뒤 24MB). 서브셋(게임에 나오는 글자 + KS X 1001 한글 2,350자)을 만들려면 `fonttools`가 필요해 설치 허락을 기다린다.
- **웹 전용 처리:**
  - 첫 화면 「눌러서 시작」(이 클릭으로 브라우저가 소리를 허락한다).
  - 휴대폰 · 태블릿(`web_android` · `web_ios`)이면 「PC에서 해 주세요」 안내와 「그래도 해 보기」를 띄운다.
  - 웹에서는 온라인 · 구판(v1) · 종료 메뉴를 숨긴다.
- **내보내기 프리셋 「Web」:** 스레드 없음(itch.io에서 COOP/COEP 헤더가 필요 없음), 로딩 화면 색은 게임 색. 시험 · 도구 폴더는 뺐다.
- **빌드 스크립트:** `game/tools/build_web.ps1` (v2 시험 → 웹 내보내기 → 파일별 크기 → zip).
- **itch.io 준비물:** `release/itch/`(저장소에는 `v2_구현/W단계_itch/`에 사본)
  - 소개 문구
  - 업로드 메모(뷰포트 1600×900, 전체 화면 켬, SharedArrayBuffer 끔, 처음에는 Restricted)
  - 스크린숏 5장(1920×1080)
- 아직 안 한 것: GIF, 브라우저 실측(크기 · 로딩 · 저장 · 소리).
