# 지시서 H2: 온라인 화면 (클라이언트)

> **보류 (2026-10-02):** 기획 포트폴리오용 1인 + AI 웹판을 주력으로 하기로 해서 온라인은 보류한다. 다시 하기로 정하기 전에는 이 지시서를 쓰지 마라.

> 먼저 `v2_구현/지시서/00_공통.md`를 읽어라. 앞 단계: **H1 온라인 서버**가 끝나 있어야 한다. F(화면 다듬기)가 끝나 있으면 좋다.

## 읽을 것
1. `v2_구현/온라인_규약.md`: H1에서 쓴 통신 규약
2. `v2_구현/12단계_평가_반영.md`: 6절
3. 화면 코드: `game/scripts/ui/v2/`, 시작 화면 `game/scripts/ui/main.gd`, `setup_screen_v2.gd`

## 목표
연습 모드 화면을 그대로 살려서 **온라인 4인 판**을 할 수 있게 한다.

## 할 일
### 1. 화면이 엔진을 직접 보지 않게
- 지금 게임 화면은 RulesV2를 직접 읽고 `apply`를 부른다. 이걸 **「판 연결」 인터페이스** 하나로 감싼다.
  - 로컬 구현: 연습 모드. 지금 RulesV2와 AI를 그대로 쓴다.
  - 원격 구현: 서버에서 받은 보기를 쓰고, 행동을 서버로 보낸다.
- 화면 코드는 두 구현을 구분하지 않는다.
- 연습 모드가 지금과 똑같이 도는지 `v2uitest`로 확인한다.

### 2. 로비
- 시작 화면에 「온라인」을 더한다.
  - 서버 주소는 설정에 저장하고, 기본값은 개발용 localhost다.
  - 이름을 입력한다.
- **방 만들기:** 참가 코드를 크게 보여 주고 복사 단추를 둔다. 방 설정(낮 제한 시간, AI 채우기)을 한다.
- **참가:** 코드를 입력한다.
- **방 화면:**
  - 자리 4개(사람 이름 / AI / 빈자리)
  - 요원 카드 2장 중 1장 고르기(CardPeek로 능력을 보여 준다)
  - 준비 단추, 방장의 「시작」
- 연결 실패, 코드 없음, 방 가득 참, 버전 다름을 각각 알린다.

### 3. 게임 화면 (온라인에서 더할 것)
- **동시 낮:**
  - 요원마다 차례 상태(대기/진행/마침)
  - 다른 사람이 지금 무엇을 하는지(「박 하사: 이동 중」)
  - 내 행동이 줄에 서 있을 때 표시
- **낮 제한 시간:** 위쪽 띠의 시계, 30초 전 경고
- **칸 찍기:** 칸이나 마커를 오른쪽 클릭(또는 길게 누름). 보드에 그 사람 색 표시가 잠깐 뜬다.
- **주사위 찜:** 내 주사위를 찜하면 동료에게 「판정용」 같은 표시가 보인다.
- **빠른 말:** 「여기로 와」, 「주사위 줄게」, 「내가 막을게」, 「잠깐」, 「좋아」 정도. 데이터로 둔다.
- **동시 비공개 투표:** 내 표만 보이고, 다른 사람은 「냈음/아직」만 보인다. 공개할 때 연출한다.
- **군자금 승인:** 3 이상 쓰는 사람이 있으면 「승인/거부」 창과 10초 시계를 띄운다.
- **사연:** 내 것만 보인다. 남의 사연은 장수와 「이룸」 여부만 보인다(이뤘을 때 공개).
- **끊김:**
  - 끊긴 사람 자리에 「AI 대신 진행 중」을 표시한다.
  - 내가 끊기면 다시 연결을 시도하고, 돌아오면 전체 보기를 받아 화면을 다시 그린다.
- **판이 끝나면:** 엔딩과 후일담을 모두 함께 본다. 「같은 방에서 다시」 단추를 둔다.

### 4. 시험
- 로컬에서 서버 1개 + 클라이언트 창 2~4개를 띄워 한 판을 끝까지 둔다(나머지 자리는 AI).
  - 화면 캡처로 확인한다.
  - 창 위치를 나눠 겹치지 않게 띄운다.
- 화면 시험(`v2uitest`)에 원격 구현 모의(가짜 서버)를 더해 로비 → 시작 → 하루 → 투표 → 끝까지 확인한다.
- 끊김과 재접속, 승인 창, 투표 공개, 제한 시간을 확인한다.

## 범위 밖
- 서버 배포와 호스팅, 계정, 매치메이킹, 음성
- 배포(H3)는 호스팅 방식을 정한 뒤 따로 지시한다. 리눅스 헤드리스 서버 내보내기, 도커, TLS(wss) 프록시가 대상이다.
