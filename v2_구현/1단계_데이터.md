# v2 구현 1단계: 카드 데이터와 검증

v2 규칙(기획서 `결사_기획서.md` 19장)의 카드를 기계가 읽을 수 있는 JSON으로 옮기고, 읽기·검증 코드를 만든다. 카드 원문은 `카드_목록_v2.md`(이하 "카드 목록")이다.

## 0. 원칙 (모든 작업자 공통)

- **v1 파일은 건드리지 않는다.** `game/data/*.json`, `game/scripts/core/*.gd`, 기존 테스트는 그대로 둔다. v2는 새 모드로 따로 산다.
- 새 파일 위치
  - 데이터: `game/data/v2/*.json`
  - 코드: `game/scripts/core/v2/game_data_v2.gd` (class_name `GameDataV2`)
  - 테스트: `game/tests/v2_data_test.gd`
- **문장은 카드 목록에서 글자 그대로 옮긴다.** 다듬거나 새로 쓰지 않는다. 한국어만 쓴다.
- JSON은 UTF-8, 들여쓰기 탭, `_comment` 키로 설명을 단다 (v1 `data/cards.json`과 같은 스타일).
- 효과·조건은 **아래 3절의 어휘만** 쓴다. 어휘가 모자라면 새 이름을 만들지 말고, 가장 가까운 것을 쓰고 `"_todo": "…"` 키에 사정을 적는다. 작업 끝에 `_todo` 목록을 보고한다.
- 칸 좌표, 거점 위치 같은 보드 정보는 v1 `data/balance.json`의 board를 그대로 쓴다 (v2에서 바꾸지 않음).
- 거점 id: `barracks`(일본군영, 0), `police_hq`(종로경찰서, 1), `prison`(서대문형무소, 2), `gg`(조선총독부, 3). 데이터에서는 문자열 id를 쓴다.
- Godot 실행 파일: `E:\Godot\Godot_v4.7.1-stable_win64_console.exe`. 테스트: `godot --headless --path game --script res://tests/v2_data_test.gd`. 새 class_name을 만든 뒤에는 한 번 `godot --headless --path game --import`를 돌려야 인식된다.

## 2. 파일 형식

모든 카드 파일은 `{"_comment": "...", "<목록 키>": [ ... ]}` 모양이다. 카드는 `id`(영문 snake_case, 파일 안에서 유일), `name`(한국어), `count`(장수, 1장이면 생략 가능)를 갖는다.

### 2-1. rules.json (C)
```json
{
  "players": 4,
  "rounds": 10,
  "team_dice_extra": 1,
  "mission_row": 3,
  "launch_min": 5,
  "forced_launch_days_left": 2,
  "exposure": {"max": 9, "thresholds": [3, 6], "loud": 1},
  "police": {"pieces": 4, "escape_distance": 3, "speed_by_alert": [2, 3, 4]},
  "hand_limit": 2,
  "item_uses_per_turn": 1,
  "bomb_slots": 1,
  "checks": {"assassin": 9, "evade": 7, "escape": 9, "sabotage": 7},
  "tiles": {"normal": 45, "event": 18, "item": 15, "check": 5, "supply": 5, "assassin": 6, "sabotage": 3, "bomb": 3},
  "traitor": {"players": [4], "shaken_needed": 2},
  "scenes": {"middle_draw": 2, "reinforce_by_alert": {"1": 0, "2": 1, "3": 2}},
  "intel_token": {"check_bonus": 1, "dice_reduce": 2},
  "saga": {"deal_per_pile": 1}
}
```
수치는 위 값으로 시작한다 (기획서 19장·카드 목록과 같음). 키를 더 넣어도 되지만 `_comment`로 뜻을 적는다.

### 2-2. threats.json (A)
```json
{"act1": [카드...], "act2": [카드...]}
```
카드: `id, name, count, text(효과 문장, 카드 목록 그대로), tone("bad"|"relief"|"mixed"), effects[]`. 2막 「회유 공작」은 `"deck_place": "top_half"`.

예:
```json
{"id": "curfew", "name": "통금령", "count": 2, "tone": "bad", "text": "오늘 모든 이동 주사위 −1 (최소 1)",
 "effects": [{"op": "dice_mod_today", "value": -1}]}
```

### 2-3. interrogation.json (A)
```json
{"cards": [{"id": "held", "name": "버텼다", "count": 7, "shaken": false, "text": "그는 이름 하나 대지 않았다."},
           {"id": "shaken", "name": "흔들렸다", "count": 5, "shaken": true, "text": "어머니 얘기가 나오자 그의 눈이 흔들렸다."}]}
```

### 2-4. missions.json (A)
```json
{"types": {"assassin": {...}, "infiltrate": {...}, "bomb": {...}, "sabotage": {...}, "coop": {...}}, "missions": [카드...]}
```
- `types`: 카드 목록 3절 "종류별 기본 규칙" 표. 각 종류 `name, how(하는 법 문장), ready(기본 결행 준비), loud(bool), condition`.
- 미션 카드: `id, name, type, intel(거점 id | "nearest" | null), rewards[](추가 보상 효과), text(추가 보상 문장)`.
- 잠입은 `base`(들어갈 거점 id)를 갖는다. 협동은 `condition`(3-3절)과 `ready`를 카드에 직접 갖는다.

### 2-5. events.json / items.json (A)
- 이벤트: `id, name, count, tone("good"|"bad"|"choice"), text, effects[]`. 고르는 이벤트는 `effects: [{"op": "choice", "options": [{"label": "숨겨 준다", "effects": [...]}, {"label": "외면한다", "effects": []}]}]`.
- 「옛 동지와의 재회」처럼 인원에 따라 다른 것은 `{"op": "if_players", "players": [4], "then": [...], "else": [...]}`.
- 아이템: `id, name, count(기획서 19.10에 장수가 없으니 아래 표대로), kind("consumable"|"persistent"), text, when("morning"|"turn"|"react_evade"|"jailed"|"any"), effects[]` 또는 지속이면 `mods[]`.
- 아이템 장수 (아이템 타일 15장): 승차권 2, 회중시계 1, 연막탄 2, 옷핀 2, 위조 통행증 2, 암호 수첩 1, 전보 1, 동지들의 엄호 1, 망원경 2, 양장 1.

### 2-6. scenes.json (B)
```json
{"strikes": {"prison": {"name": "형무소 해방", "base": "prison", "on_launch": [], "entry": 카드, "middle": [카드×4], "final": 카드},
             "barracks": ..., "police_hq": ..., "gg": ...},
 "reinforce": [카드×4]}
```
- 카드: `id, name, where("inside"|"adjacent"|"inside_or_adjacent"), condition(3-3절), on_fail[](효과, 없으면 []), stop_text(여기서 멈추면 문장, 따옴표 없이)`.
- 마지막 장면의 stop_text는 "한 걸음이 모자랐다 —" 뒤의 문장만 넣는다.
- 경찰서 결행의 "보급 타일을 모두 다시 채움"은 `on_launch: [{"op": "refill_supply"}]`.

### 2-7. sagas.json (B)
```json
{"piles": {"a": ["place", "own"], "b": ["risk", "bond", "strike"]}, "sagas": [카드...]}
```
- 카드: `id, name, branch("place"|"own"|"risk"|"bond"|"strike"), story(사연 한 줄), condition(3-4절), condition_text(조건 문장), reward[](효과), reward_text, lure(회유 문구, 따옴표 없이), redraw_for[](캐릭터 id 목록), epilogue: {"win_done": "", "win_fail": "", "lose_done": "", "lose_fail": "", "traitor": ""}`.
- 이룰 수 없는 칸("(결행이 성공해야 이룰 수 있어 없음)")은 `null`.
- 「약속의 반지」는 `"check_at": "launch"`. 결행 갈래는 `"act": 2`.

### 2-8. characters.json (B)
```json
{"factions": {"kb": {"name": "한국광복군", "theme": "생존·계획"}, "uy": {...}, "ub": {"name": "의병", ...}, "ug": {"name": "경성 지하조직", ...}},
 "characters": [카드...]}
```
- v1의 세력 키 `kb, uy, ub`를 그대로 쓰고 지하조직은 `ug`.
- 카드: `id, name, faction, gender("m"|"f"), origin(출신 한 줄), persona("bold"|"careful"|"support"), trait_text, trait: {"mods": [...]} , ability_text, ability: {"name": "무전 지원", "when": "morning"|"turn", "target": ..., "effects": [...]}`.
- 캐릭터 id 예: `yun, park, han, oh, seok, mun, gaeddong, makrye, choi, jeong, seo, lee`. sagas의 `redraw_for`도 이 id를 쓴다 (B가 두 파일을 함께 만드니 맞춘다).

`self`, `ally`(동료 하나를 고름), `ally_same_cell`, `ally_adjacent`(같은 칸이나 옆 칸 동료), `ally_in_range`(range 필요), `all`, `allies`(동료 모두, 본인과 변절자 제외 — 3단계 추가), `isolated`(고립된 요원: 가장 가까운 동료와 가장 먼), `wanted`(수배된 요원: 투옥 횟수 최다), `nearest_to_base`(base 필요), `all_jailed`

`where`: `"inside"`, `"adjacent"`, `"inside_or_adjacent"`, 또는 거점 id.

## 4. GameDataV2 (C)

```gdscript
class_name GameDataV2
extends RefCounted
const DIR := "res://data/v2/"
static func load_default() -> GameDataV2   # 캐시
var rules, threats, interrogation, missions, events, items, scenes, sagas, characters: Dictionary
var board  # v1 GameData.load_default()의 size/start/bases/base_names를 재사용 (v1 코드를 고치지 않고 읽기만)
func threat_deck(act: int) -> Array        # count만큼 펼친 id 목록
func mission(id) / event(id) / item(id) / saga(id) / character(id) / strike(base_id) -> Dictionary
func validate() -> Array[String]
```
`validate()`가 잡을 것:
- 모든 `op`, `kind`, `stat`, `who`/`target`, `where`가 3절 어휘 안에 있는가 (`KNOWN_*` 상수로 둠)
- 장수: 위협 1막 24, 2막 11, 심문 12(흔들렸다 5), 미션 20(협동 5), 이벤트 18장 10종, 아이템 10종 15장, 장면 결행마다 진입 1·중간 4·마지막 1, 경비 강화 4, 사연 20(더미 가 9·나 11), 캐릭터 12(소속마다 3, 여성 4)
- id 중복, 빈 `name`/`text`
- 사연 `redraw_for`의 캐릭터 id가 실제로 있는가, `epilogue` 다섯 키가 다 있는가 (null 허용)
- 미션 `intel`과 장면 `strike`의 거점 id가 유효한가
- 타일 장수 합이 빈칸 수(121 − 1 − 4 = 116) 이하
- `_todo`가 있는 카드를 경고로 모아 출력 (오류는 아님)
