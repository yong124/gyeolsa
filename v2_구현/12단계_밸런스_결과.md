## 2. 바꾼 수치

### 2막 장면 (`data/v2/scenes.json`)
이유: 지는 판이 거의 2막 장면에서만 났고(장면 돌파율 대부분 93~100%), 반격 목표나 군자금은 승률을 거의 못 움직였다(스윕 3절). 장면 눈금이 가장 크게 움직인다.

| 거점 | 장면 | 전 → 후 |
|---|---|---|
| 일본군영 | 철조망 (합) | 6 → 7 |
| | 장교 숙소 (판정) | 8 → 9 |
| | 군견 (두 명 판정) | 7 → 8 |
| | 사령관실 (암살 판정) | 10 → 12 |
| 종로경찰서 | 당직 순사 (판정) | 8 → 12 |
| | 경보 차단 (합) | 8 → 11 |
| | 지하 유치장 (판정) | 8 → 12 |
| 서대문형무소 | 담 넘기 (합) | 6 → 7 |
| | 간수 제압 (두 명 판정) | 7 → 8 |
| | 비상종 (판정) | 8 → 9 |
| | 옥문 | 11 (그대로) |
| 조선총독부 | 정문 (판정) | 9 → 12 |
| | 통신실 (합) | 10 → 13 |
| | 근위대 (두 명 판정) | 7 → 9 |
| | 깃발 (판정) | 9 → 11 |

- 한 번에 모든 장면을 같은 폭으로 올리면 거점 격차가 커졌다(전부 +2: 형무소 10%, 군영 42%, 총독부 64%, 경찰서 60%). 그래서 거점마다 폭을 따로 잡았다.
- 마지막 장면은 +1만 올려도 크게 움직인다(군영 마지막 +2 더 → 군영 6%). 마지막 장면은 가장 조금만 건드렸다.
- 경찰서의 눈금 12, 총독부 정문 12, 통신실 합 13은 주사위 두 개로는 거의 닿지 않는 값이다. 군자금 지불·아이템·수감 요원 같은 다른 길이 열려 있는 장면(`any_of`)이라 이긴다. 제안 참고.
- 경비 강화 장면은 건드리지 않았다.

### AI 계수 (`rules.json`의 `ai.mission`)
| 계수 | 전 → 후 | 이유 |
|---|---|---|
| `urgent` (기한 임박 가중) | 1.0 → 4.0 | 일제 작전 마커를 기한 안에 쫓지 않아 막은 비율이 28%였다 |
| `penalty` (못 막을 때 벌칙 가중) | 0.8 → 2.4 | 같은 이유 |
| `ready` (결행 준비 가치) | 1.0 → 0.5 | 위 둘을 올리면 작전만 쫓다 결행이 늦어 형무소 승률이 눌려 균형을 맞춤 |

작전 기한을 늘려도(+1일) 막은 비율은 28%대로 그대로였다. 시간이 아니라 AI가 마커를 안 쫓는 문제였다. 지시서대로 **AI가 약해서 생긴 차이는 수치로 메우지 않고 AI를 고쳤다.** 이 변경은 승률을 5%p쯤 내렸고(결행이 늦어짐), 그 몫은 형무소 마지막 장면을 12에서 11로 되돌려 메웠다.

## 3. 스윕 기록 (400판, 참고)
| 실험 | 승률 | 읽은 것 |
|---|---|---|
| 반격 목표 7 → 8 · 9 | 74.0 · 73.5% | 반격을 이미 86% 막아 영향이 없다 |
| 군자금 시작 2 → 1 · 0 | 74.0 · 65.8% | 1은 같고 0이면 결행이 늦어진다. 규칙 수치라 그대로 둠 |
| 장면 전부 +1 · +2 | 67.8 · 47.5% | +2는 형무소 10%로 격차가 커진다 |

| 장면 군자금 지불 +1 | (같음) | AI가 장면 매수에 군자금을 거의 안 씀 |

## 4. 남은 문제
- **승률 49%는 AI 4명 목표(45~55%)의 가운데지만, 시드를 바꾸면 흔들린다.** 시드 910000에서는 54.8%이고 총독부가 68%로 높았다. 거점 격차 14.8%p도 15%p에 빠듯하다.
- 군영이 43%로 가장 낮고 총독부가 58%로 가장 높다. 군영 마지막(암살 12)은 눈금 하나에 크게 흔들린다.
- 장면 눈금이 10을 훌쩍 넘는 곳(경찰서 판정 12, 총독부 통신실 합 13)은 숫자로 읽으면 이상하다. 이기는 길은 아이템·군자금·두 명 이상 같은 다른 조건이다.
- 군자금 지불 장면 값을 올려도 AI 결과가 같다. AI가 장면 매수를 거의 하지 않는다(판당 0.01번). 사람은 쓸 수 있다.
- 사연 이룸률이 낮은 것이 많다: 부호 0%, 첫걸음 2%, 마지막 전보 4%, 주모의 부탁 1%. 요원 승률에는 영향이 없지만 사연이 사실상 안 나오는 요원이 있다.
- 놓친 미션이 암살과 연락에 몰린다(판당 0.22). 작업(공작) 미션 이룬 비율은 24%로 낮다.

## 5. 사람 플레이테스트에서 볼 것
- 사람 4명 기준 목표는 50~60%다. 사람이 협력을 더 잘하면 이보다 쉬울 수 있다. 첫 판 승률이 높으면 군영·경찰서 눈금을 먼저 내린다.
- 장면 눈금이 너무 높아 보이는지, 「합 13」 같은 표기가 이해되는지.
- 일제 작전을 사람도 6할 막을 수 있는지(AI는 6할).
- 결행이 5~7일째에 나는지(AI는 6.2일째).
- 한 걸음이 모자라 지는 판의 비율(AI 22%)이 사람에게 아쉬움으로 느껴지는지, 억울함으로 느껴지는지.

## 6. 제안 (규칙을 바꾸는 것이라 구현하지 않았다)
- 눈금이 12·13에 닿는 장면은 눈금 대신 「사람 수」·「아이템」·「군자금」 같은 조건을 늘려 난이도를 조정하면 읽기 쉽다.
- 마지막 장면이 눈금 하나에 크게 흔들린다(군영 +1 → 승률 약 30%p). 마지막 장면에 보완 길(군자금·아이템)을 하나 열면 조정 폭이 넓어진다.
- 군자금이 사실상 시작 2로 끝난다(D단계 제안). 장면 매수가 안 쓰이는 문제와 함께 본다.
