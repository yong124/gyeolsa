# itch.io 업로드 메모 (사용자가 직접)

## 순서
1. itch.io 로그인 → Dashboard → **Create new project**
2. **Kind of project: HTML**
3. **Uploads**: `build/GwangbokIF_web_v2.1.2.zip`(최신) 업로드 → **This file will be played in the browser** 체크
4. **Embed options**
   - Viewport dimensions: **1280 × 720** (2026-10-13 바꿈: 1600 × 900이면 1366 · 1440 폭 노트북에서 페이지가 가로로 넘쳐 스크롤이 생기고 「Run game」이 한쪽으로 치우친다. 게임은 `stretch aspect=expand`라 1280 × 720에 맞춰 0.8배로 그려진다. 더 크게는 전체 화면 단추로)
   - **Fullscreen button**: 켬
   - **Mobile friendly**: 끔 (PC 전용, 휴대폰으로 열면 게임이 「PC에서 해 주세요」 안내를 띄움)
   - **SharedArrayBuffer support**: **끔** (스레드 없는 내보내기라 필요 없음. 켜면 다른 외부 링크가 막힐 수 있음)
   - Automatically start on page load: 끔 (게임 안에 「눌러서 시작」이 있음)
5. **Details**: `release/itch/소개.md` 문구 붙여 넣기 · Genre: Strategy · Tags: board-game, cooperative, history, korean, singleplayer
6. **Screenshots**: `release/itch/screenshots/` 5장 · Cover image: `release/itch/cover_630x500.png`. **공개 페이지(2026-10-13 확인)에는 스크린샷 · 커버가 0장이고 크레딧이 「[이름]」 그대로다.** `소개.md`를 다시 붙여 넣는다
   - Edit theme: 배경을 기본 회색 대신 게임 종이색(예: `#2b2118` 바탕 · `#f1e6cc` 글)으로
7. **Visibility**: 처음에는 **Restricted**(비밀 링크)로 두고 친구 3~5명에게 시험 → 고친 뒤 **Public**
8. 가격: No payments (무료)

## 확인할 것 (올린 뒤 비공개 링크로)
- Chrome · Edge · Firefox에서 첫 화면 → 「눌러서 시작」 → 소리가 남
- 「바로 시작」으로 한 판이 시작되고, 새로고침 뒤 「이어하기」가 뜸 (저장은 브라우저 IndexedDB)
- 전체 화면 단추, 창 크기 바꾸기
- 첫 로딩 시간 (목표: 일반 회선에서 10초 안)
